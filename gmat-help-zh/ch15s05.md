# 修改估计脚本以使用平滑器改进估计（Modify the estimation script to use a smoother to improve the estimates）
> 译自 GMAT R2026a 帮助文档 ch15s05.html

现在我们要在脚本中添加一个"Smoother（平滑器）"。平滑器让我们能改进定轨（估计）状态：它从最后一个测量到第一个测量反向运行滤波器，然后把前向滤波器和反向滤波器的结果"融合"为一个结合了前向与反向滤波器信息的新估计。反向滤波器自动从前向滤波器的最后一个估计状态初始化。平滑器不会改进从最后一个前向滤波测量之后做出的任何预报的精度，因为滤波器和平滑器在该时刻的估计相同。平滑器的主要优势是改进测量跨度内（也称"定轨"跨度）状态的精度。

在 GMAT 中，滤波器实例必须挂接到平滑器，因此平滑器必须与前向滤波器在同一脚本和任务序列中运行。我们将对滤波脚本做以下编辑。

1. 打开你的滤波脚本文件。
2. 在滤波脚本窗口中输入或粘贴以下内容。
   a. 这必须放在"任务序列"之外（BeginMissionSequence 语句之前）。如果你愿意，就放在滤波器正下方。

```
%
%   Smoother
%

Create Smoother FPS;

FPS.Filter               = EKF;
FPS.ShowProgress         = True;
FPS.ShowAllResiduals     = On;
FPS.ReportFile           = 'smoother.txt';
FPS.MatlabFile           = 'smoother.mat';
```

上述脚本创建平滑器 FPS：Filter 关联 EKF 滤波器，显示进度与全部残差，报告文件 smoother.txt，MATLAB 文件 smoother.mat。

3. 在脚本窗口底部，点击 "Save,Sync" 按钮。

平滑器有许多不同类型。GMAT 实现的是 "Fraser-Potter" 平滑器。其细节见参考文献 2。配置平滑器时，我们挂接前向滤波器的实例，它现在将从测量结束时间开始反向运行。与滤波器一样，我们可以在平滑器上设置标志，以在控制台窗口产生详细输出并绘制反向滤波器的残差图（ShowProgress 和 ShowAllResiduals）。我们还为平滑器报告文件和平滑器 MATLAB 数据文件指定了输出文件，类似于从滤波器得到的文件。

4. 按下面所示更新任务序列（添加 RunSmoother 命令），然后点击 "Save,Sync"。

```
%
%   Mission sequence
%

BeginMissionSequence

EstSat.OrbitErrorCovariance = diag([1e-2 1e-2 1e-2 4e-10 4e-10 4e-10]);

RunEstimator EKF;
RunSmoother FPS;
```

如你所见，RunSmoother 命令的工作方式与 RunSimulator 和 RunEstimator 完全相同。

5. 点击 "Save,Sync,Run" 按钮、点击工具栏中的蓝色 "Run" 按钮，或按 F5 键运行脚本。

脚本应在几秒内完成。滤波器将先运行并生成我们已经见过的相同输出。滤波器运行后，平滑器将运行。如果你仔细观察滤波器残差绘图窗口，应看到平滑器运行时它实际上反向（从右到左）重新绘制了残差。此外，你会在控制台窗口中看到更多输出，这次来自平滑器运行。我们可以把发生的事情总结如下：

   i. 滤波器（在 RunEstimator EKF 命令中）从第一个到最后一个测量前向运行；
   ii. 平滑器（在 RunSmoother FPS 命令中）从最后一个测量到第一个测量反向运行滤波器；
   iii. 然后平滑器前向运行（仍在 RunSmoother FPS 命令中），计算前向和反向滤波器状态估计的协方差加权平均，得到前向平滑器估计。

为理解这一切，让我们转到输出目录，查看平滑器输出文件。
