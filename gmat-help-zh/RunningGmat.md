# 运行 GMAT（Running GMAT）
> 译自 GMAT R2026a 帮助文档 RunningGmat.html

## 启动 GMAT（Starting GMAT）

如果您是通过 `.zip` 文件或自行编译系统安装的 GMAT，请找到 GMAT 的 `bin` 目录，双击 `GMAT.exe`。

要从命令行启动 GMAT，运行 `GMAT.exe`。有多种命令行参数可用；详见《[命令行用法（Command-Line Usage）](CommandLine.md)》。

## 退出 GMAT（Exiting GMAT）

在 Windows 或 Linux 上结束 GMAT 会话：在菜单栏中单击 File（文件），然后单击 Exit（退出）。在 macOS 上：在菜单栏中单击 GMAT，然后单击 Quit GMAT（退出 GMAT），或按 **Command**+**Q**。
