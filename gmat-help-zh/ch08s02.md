# 配置燃料箱、航天器属性、机动、传播器、差分修正器、坐标系与图形（Configure Fuel Tank, Spacecraft properties, Maneuvers, Propagators, Differential Corrector, Coordinate Systems and Graphics）
> 译自 GMAT R2026a 帮助文档 ch08s02.html

在本教程中，您需要打开 GMAT 并加载默认任务。要加载默认任务，请单击 **New Mission**（新建任务）（> [图：New Mission 工具栏图标]），或启动一个新的 GMAT 会话。我们将修改 **DefaultSC**，把航天器的初始状态设置为一条出射双曲线轨迹。

## 创建燃料箱（Create Fuel Tank）

我们需要创建一个燃料箱，以便查看每次脉冲机动后消耗了多少燃料。稍后我们将修改 **DefaultSC** 资源，并把该燃料箱挂接到航天器上。

1. 在 **Resources**（资源）树中，右键单击 **Hardware**（硬件）文件夹，指向 **Add**（添加），然后单击 **ChemicalTank**（化学燃料箱）。此时将创建一个名为 **ChemicalTank1** 的新资源。
2. 右键单击 **ChemicalTank1**，然后单击 **Rename**（重命名）。
3. 在 **Rename**（重命名）框中，输入 **MainTank**，然后单击 **OK**（确定）。
4. 双击 **MainTank** 以编辑其属性。
5. 按下表设置各项值。

**表 8.1. MainTank 设置**

| 字段 | 值 |
|------|-----|
| **Fuel Mass**（燃料质量） | `1718` |
| **Fuel Density**（燃料密度） | `1000` |
| **Pressure**（压力） | `5000` |
| **Volume**（容积） | `2` |

6. 单击 **OK**（确定）保存这些更改。

## 修改 DefaultSC 资源（Modify the DefaultSC Resource）

我们需要对 **DefaultSC** 做一些小的修改，以定义航天器的初始状态并将燃料箱挂接到航天器上。

1. 在 **Resources**（资源）树中，在 **Spacecraft**（航天器）文件夹下，右键单击 **DefaultSC**，然后单击 **Rename**（重命名）。
2. 在 **Rename**（重命名）框中，输入 **MAVEN**，然后单击 **OK**（确定）。
3. 双击 **MAVEN** 以编辑其属性。确保已选中 **Orbit**（轨道）选项卡。
4. 按下表设置各项值。

**表 8.2. MAVEN 设置**

| 字段 | 值 |
|------|-----|
| **Epoch Format**（历元格式） | **UTCGregorian** |
| **Epoch**（历元） | `18 Nov 2013 20:26:24.315` |
| **Coordinate System**（坐标系） | **EarthMJ2000Eq** |
| **State Type**（状态类型） | **Keplerian**（开普勒根数） |
| **Elements**（根数）下的 **SMA**（半长轴） | `-32593.21599272796` |
| **Elements** 下的 **ECC**（偏心率） | `1.202872548116185` |
| **Elements** 下的 **INC**（轨道倾角） | `28.80241266404142` |
| **Elements** 下的 **RAAN**（升交点赤经） | `173.9693759331483` |
| **Elements** 下的 **AOP**（近地点幅角） | `240.9696529532764` |
| **Elements** 下的 **TA**（真近点角） | `359.9465533778069` |

5. 现在单击 **Tanks**（燃料箱）选项卡。
6. 在 **Available Tanks**（可用燃料箱）下，您将看到 **MainTank**。这就是我们之前创建的燃料箱。
7. 我们通过将 **MainTank** 移入 **Selected Tanks**（已选燃料箱）框，把它挂接到航天器 **MAVEN** 上。在 **Available Tanks** 下选择 **MainTank**，然后将其移到右侧的 **Selected Tanks** 下。
8. 单击 **OK**（确定）保存这些更改。

## 创建机动（Create the Maneuvers）

本教程需要两个 **ImpulsiveBurn**（脉冲机动）资源。下面我们将重命名默认的 ImpulsiveBurn 并新建一个。我们还将选择之前创建的燃料箱，以便为机动提供燃料。

1. 在 **Resources**（资源）树中，在 **Burns**（机动）文件夹下，右键单击 **DefaultIB**，然后单击 **Rename**（重命名）。
2. 在 **Rename**（重命名）框中，输入 **TCM**（Trajectory Correction Maneuver，轨道修正机动的缩写），然后单击 **OK**（确定）。
3. 双击 **TCM** 以编辑其属性。
4. 在 **Mass Change**（质量变化）下，选中 **Decrement Mass**（质量递减）。
5. 在 **Mass Change** 下的 **Tank**（燃料箱）字段中，从下拉菜单选择 **MainTank**。
6. 单击 **OK**（确定）保存这些更改。
7. 右键单击 **Burns**（机动）文件夹，指向 **Add**（添加），然后单击 **ImpulsiveBurn**。此时将创建一个名为 **ImpulsiveBurn1** 的新资源。
8. 将新的 **ImpulsiveBurn1** 资源 **Rename**（重命名）为 **MOI**（Mars Orbit Insertion，火星轨道入轨的缩写），然后单击 **OK**（确定）。
9. 双击 **MOI** 以编辑其属性。
10. 在 **Coordinate System**（坐标系）下的 **Origin**（原点）字段中，选择 **Mars**（火星）。
11. 在 **Mass Change**（质量变化）下，选中 **Decrement Mass**（质量递减）。
12. 在 **Mass Change** 下的 **Tank**（燃料箱）字段中，从下拉菜单选择 **MainTank**。
13. 单击 **OK**（确定）保存这些更改。

## 创建传播器（Create the Propagators）

本教程需要添加三个传播器。下面我们将重命名默认的 **DefaultProp**，并再创建两个传播器。

1. 在 **Resources**（资源）树中，在 **Propagators**（传播器）文件夹下，右键单击 **DefaultProp**，然后单击 **Rename**（重命名）。
2. 在 **Rename**（重命名）框中，输入 **NearEarth**（近地），然后单击 **OK**（确定）。
3. 双击 **NearEarth** 以编辑其属性。
4. 按下表设置各项值。

**表 8.3. NearEarth 设置**

| 字段 | 值 |
|------|-----|
| **Integrator**（积分器）下的 **Initial Step Size**（初始步长） | `600` |
| **Integrator** 下的 **Accuracy**（精度） | `1e-013` |
| **Integrator** 下的 **Min Step Size**（最小步长） | `0` |
| **Integrator** 下的 **Max Step Size**（最大步长） | `600` |
| **Gravity**（引力）下的 **Model**（模型） | **JGM-2** |
| **Gravity** 下的 **Degree**（阶） | `8` |
| **Gravity** 下的 **Order**（次） | `8` |
| **Drag**（大气阻力）下的 **Atmosphere Model**（大气模型） | **None**（无） |
| **Force Model**（力模型）下的 **Point Masses**（质点） | 添加 **Luna**（月球）和 **Sun**（太阳） |
| **Force Model** 下的 **Use Solar Radiation Pressure**（使用太阳光压） | 选中此字段 |

5. 单击 **OK**（确定）保存这些更改。
6. 右键单击 **Propagators**（传播器）文件夹，然后单击 **Add Propagator**（添加传播器）。此时将创建一个名为 **Propagator1** 的新资源。
7. 将新的 **Propagator1** 资源 **Rename**（重命名）为 **DeepSpace**（深空），然后单击 **OK**（确定）。
8. 双击 **DeepSpace** 以编辑其属性。
9. 按下表设置各项值。

**表 8.4. DeepSpace 设置**

| 字段 | 值 |
|------|-----|
| **Integrator**（积分器）下的 **Type**（类型） | **PrinceDormand78** |
| **Integrator** 下的 **Initial Step Size**（初始步长） | `600` |
| **Integrator** 下的 **Accuracy**（精度） | `1e-012` |
| **Integrator** 下的 **Min Step Size**（最小步长） | `0` |
| **Integrator** 下的 **Max Step Size**（最大步长） | `864000` |

| **Force Model** 下的 **Primary Body**（主天体） | **None**（无） |

| **Force Model** 下的 **Use Solar Radiation Pressure**（使用太阳光压） | 选中此字段 |

10. 单击 **OK**（确定）保存这些更改。
11. 右键单击 **Propagators**（传播器）文件夹，然后单击 **Add Propagator**（添加传播器）。此时将创建一个名为 **Propagator1** 的新资源。
12. 将新的 **Propagator1** 资源重命名为 **NearMars**（近火星），然后单击 **OK**（确定）。
13. 双击 **NearMars** 以编辑其属性。
14. 按下表设置各项值。

## 创建差分修正器（Create the Differential Corrector）

我们稍后要创建的两个 `Target`（目标求解）序列需要一个 `DifferentialCorrector`（差分修正器）资源才能运行，因此现在先创建一个。其设置保持默认值即可。

1. 在 **Resources**（资源）树中，如果 **Solvers**（求解器）文件夹尚未展开，请将其展开。
2. 右键单击 **Boundary Value Solvers**（边值求解器）文件夹，指向 **Add**（添加），然后单击 **DifferentialCorrector**。此时将创建一个名为 **DC1** 的新资源。
3. 将新的 **DC1** 资源 **Rename**（重命名）为 **DefaultDC**，然后单击 **OK**（确定）。

## 创建坐标系（Create the Coordinate Systems）

我们稍后在第一个 **Target** 序列下将要定义的 BdotT 和 BdotR 约束，要求我们创建坐标系。稍后将要创建的 Orbit View（轨道视图）资源也需要坐标系资源才能运行。我们将创建以太阳和火星为中心的坐标系。现在就来创建它们。

1. 在 **Resources**（资源）树中，右键单击 **Coordinate Systems**（坐标系）文件夹，然后单击 **Add Coordinate System**（添加坐标系）。此时将弹出一个标题为 **New Coordinate System**（新建坐标系）的新对话框。
2. 在 **Coordinate System Name**（坐标系名称）框中输入 **SunEcliptic**（太阳黄道）。
3. 在 **Origin**（原点）字段下，选择 **Sun**（太阳）。
4. 在 **Axes**（轴）下的 **Type**（类型）中，选择 **MJ2000Ec**。
5. 单击 **OK**（确定）保存这些更改。您将看到 **Coordinate Systems** 文件夹下创建了一个新坐标系 **SunEcliptic**。
6. 右键单击 **Coordinate Systems** 文件夹，然后单击 **Add Coordinate System**（添加坐标系）。此时将弹出一个标题为 **New Coordinate System** 的新对话框。
7. 在 **Coordinate System Name** 框中输入 **MarsInertial**（火星惯性系）。
8. 在 **Origin**（原点）字段下，选择 **Mars**（火星）。
9. 在 **Axes**（轴）下的 **Type**（类型）中，选择 **BodyInertial**（天体惯性系）。
10. 单击 **OK**（确定）保存这些更改。您将看到 **Coordinate Systems** 文件夹下创建了一个新坐标系 **MarsInertial**。

## 创建轨道视图（Create the Orbit Views）

本教程需要三个 **OrbitView**（轨道视图）资源。下面我们将重命名默认的 **OrbitView** 并新建两个。我们需要三个图形窗口，以便分别可视化以地球、太阳和火星为中心的航天器轨迹。

1. 在 **Resources**（资源）树中，在 **Output**（输出）文件夹下，右键单击 **DefaultOrbitView**，然后单击 **Rename**（重命名）。
2. 在 **Rename**（重命名）框中，输入 **EarthView**（地球视图），然后单击 **OK**（确定）。
3. 在 **Output**（输出）文件夹中，删除 **DefaultGroundTrack**（默认星下点轨迹）。
4. 双击 **EarthView** 以编辑其属性。
5. 按下表设置各项值。

**表 8.6. EarthView 设置**

| 字段 | 值 |
|------|-----|
| **View Definition**（视图定义）下的 **View Scale Factor**（视图比例因子） | `4` |
| **View Definition** 下的 **View Point Vector**（视点矢量）各框 | `0, 0, 30000` |

6. 单击 **OK**（确定）保存这些更改。
7. 右键单击 **Output**（输出）文件夹，指向 **Add**（添加），然后单击 **OrbitView**。此时将创建一个名为 **OrbitView1** 的新资源。
8. 将新的 **OrbitView1** 资源 **Rename**（重命名）为 **SolarSystemView**（太阳系视图），然后单击 **OK**（确定）。
9. 双击 **SolarSystemView** 以编辑其属性。
10. 按下表设置各项值。

**表 8.7. SolarSystemView 设置**

| 字段 | 值 |
|------|-----|
| 从 **View Object**（视图对象）下的 **Celestial Object**（天体）中，将以下对象添加到 **Selected Celestial Object**（已选天体）框 | **Mars**（火星）、**Sun**（太阳）（不要移除 **Earth**（地球）） |
| **View Definition**（视图定义）下的 **Coordinate System**（坐标系） | **SunEcliptic** |
| **View Definition** 下的 **View Point Reference**（视点参考） | **Sun**（太阳） |
| **View Definition** 下的 **View Point Vector**（视点矢量）各框 | `0, 0, 5e8` |
| **View Definition** 下的 **View Direction**（视线方向） | **Sun**（太阳） |
| **View Up Definition**（视图向上定义）下的 **Coordinate System**（坐标系） | **SunEcliptic** |

11. 单击 **OK**（确定）保存这些更改。
12. 右键单击 **Output**（输出）文件夹，指向 **Add**（添加），然后单击 **OrbitView**。此时将创建一个名为 **OrbitView1** 的新资源。
13. 将新的 **OrbitView1** 资源 **Rename**（重命名）为 **MarsView**（火星视图），然后单击 **OK**（确定）。
14. 双击 **MarsView** 以编辑其属性。
15. 按下表设置各项值。

**表 8.8. MarsView 设置**

| 字段 | 值 |
|------|-----|
| 从 **View Object**（视图对象）下的 **Celestial Object**（天体）中，将以下对象添加到 **Selected Celestial Object**（已选天体）框 | **Mars**（火星）（您不必移除 **Earth**（地球）） |
| **View Definition**（视图定义）下的 **Coordinate System**（坐标系） | **MarsInertial** |
| **View Definition** 下的 **View Point Reference**（视点参考） | **Mars**（火星） |
| **View Definition** 下的 **View Point Vector**（视点矢量）各框 | `22000, 22000, 0` |
| **View Definition** 下的 **View Direction**（视线方向） | **Mars**（火星） |
| **View Up Definition**（视图向上定义）下的 **Coordinate System**（坐标系） | **MarsInertial** |

16. 单击 **OK**（确定）保存这些更改。
