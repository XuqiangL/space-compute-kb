# 运行包含第一个和第二个 Target 序列的任务（Run the Mission with first and second Target Sequences）
> 译自 GMAT R2026a 帮助文档 ch08s05.html

在运行任务之前，单击 **Save**（保存）（> [图：Save Mission 工具栏图标]）。这将保存我们在 **Mission**（任务）树中所做的额外更改。然后单击 **Run**（运行）（> [图：Run Mission 工具栏图标]）。第一个 **Target** 序列将在一次迭代内收敛。这是因为我们之前已将解存储为初始条件。第二个 **Target** 序列可能在 10 到 11 次迭代后收敛。

随着任务的运行，您将看到 GMAT 求解第二个 **Target** 序列的目标求解问题。每次迭代和摄动都以浅蓝色显示在 **MarsView** 窗口中，最终解以红色显示。任务完成后，**MarsView** 三维视图应与下图所示一致。**EarthView** 和 **SolarSystemView** 三维视图与之前相同。您可以多次运行该任务，以观察目标求解的进行过程。

> [图 8.28：3D view of Mars Capture orbit after MOI maneuver (MarsView)（MOI 机动后火星捕获轨道的三维视图，火星视图）]

如果您要继续开发此任务，可以将第二个 **Target** 序列的最终解存储为 **MOI** 资源的初始条件。这样，当您做出小的更改时，后续运行将花费更少的时间。为此，请执行以下步骤：

1. 在 **Mission**（任务）树中，双击 **Mars Capture**（火星捕获）以编辑其属性。
2. 单击 **Apply Corrections**（应用修正）。
3. 现在重新运行任务。如果您在消息窗口中查看结果，将会看到现在第二个 **Target** 序列也在一次迭代内收敛。这是因为您已将解存储为初始条件。现在，每当您重新运行任务时，第一个和第二个 Target 序列都将在一次迭代内收敛。
4. 在 **Mission**（任务）树中，双击 **Vary MOI.V**，您会注意到 **Initial Value**（初始值）框中的值已更新为第二个 **Target** 序列的最终解。

如果您想知道 MOI 机动的 ΔV（速度增量）矢量值以及机动期间消耗了多少燃料，请执行以下步骤：

1. 在 **Mission**（任务）树中，右键单击 **Apply MOI**，然后单击 **Command Summary**（命令摘要）。
2. 向下滚动，在 `Maneuver Summary`（机动摘要）标题下，ΔV 矢量的各值为：

```
Delta V Vector:
Element 1:   -1.6034665169868 km/s
Element 2:    0.0000000000000 km/s
Element 3:    0.0000000000000 km/s
```

3. 向下滚动，在 `Mass depletion from MainTank`（MainTank 燃料消耗）标题下，`Delta V` 和 `Mass Change`（质量变化）告诉您 MOI 机动的幅值以及该机动消耗了多少燃料：

```
Delta V:        1.6034665169868 km/s
Mass change:   -1076.0639629424 kg
```

为了确认第二个 **Target** 序列的目标已成功达成，让我们通过以下步骤查看 **Achieve RMAG** 命令的命令摘要：

1. 在 **Mission**（任务）树中，右键单击 **Achieve RMAG**，然后单击 **Command Summary**（命令摘要）。
2. 在 **Coordinate System**（坐标系）下，选择 **MarsInertial**。
3. 在 `Keplerian State`（开普勒状态）和 `Spherical State`（球面状态）标题下，查看 `TA`（真近点角）和 `RMAG`（半径幅值）的值。您可以看到，捕获轨道在远心点的期望半径已成功实现：

```
TA   =   180.00000241484 deg
RMAG =   12000.019889021 km
```
