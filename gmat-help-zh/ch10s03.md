# 配置任务序列（Configure the Mission Sequence）
> 译自 GMAT R2026a 帮助文档 ch10s03.html

现在我们准备配置 **Mission Sequence（任务序列）**。我们首先插入一个 **Global（全局）** 命令，将在 **TargeterInsideFunction** 函数内声明为全局的同一批对象声明为全局。接着插入 **CallGmatFunction** 命令，调用并启动包含第一个 target 序列的 **TargeterInsideFunction** 函数。第一个 target 序列将求解实现 B 矢量的 BdotT 和 BdotR 分量所需的 **TCM** 机动值。BdotT 目标为 0 km，BdotR 目标为非零值，以生成倾角 90 度的极地轨道。

第二个 target 序列采用单个基于火星的反速度方向（-V）机动，并包含一个传播序列。这个反速度方向机动将在近拱点发生。该机动的目的是通过瞄准远拱点位置矢量模 12,000 km 来实现 MOI。本教程的基本步骤如下。

## 创建启动第一个 Target 序列的命令

现在创建执行第一个 **Target** 序列所需的命令。图 10.3"第一个 Target 序列的任务序列"展示了你完成本节步骤后 **Mission** 树的配置。

> [图 10.3：第一个 Target 序列的任务序列]

按以下步骤设置第一个 Target 序列：

1. 点击 **Mission（任务）** 选项卡，显示 **Mission** 树。
2. 你会看到已存在一个 **Propagate1** 命令。我们需要删除此命令。
3. 右键点击 **Propagate1** 命令，点击 **Delete（删除）**。
4. 右键点击 **Mission Sequence** 文件夹，指向 **Append（追加）**，点击 **Global**。将创建一个名为 **Global1** 的新命令。
5. 右键点击 **Global1**，点击 **Rename**。在 **Rename** 框中输入 **Make Objects Global**，点击 **OK**。
6. 右键点击 **Mission Sequence** 文件夹，指向 **Append**，点击 **CallGmatFunction**。将创建一个名为 **CallGmatFunction1** 的新命令。
7. 右键点击 **CallGmatFunction1**，点击 **Rename**。在 **Rename** 框中输入 **Target Desired B-Plane Coord. From Inside Function**，点击 **OK**。
8. 右键点击 **Mission Sequence** 文件夹，指向 **Append**，点击 **Report**。将创建一个名为 **Report1** 的新命令。
9. 右键点击 **Report1**，点击 **Rename**。在 **Rename** 框中输入 **Report Parameters**，点击 **OK**。

## 配置任务树以运行第一个 Target 序列

现在结构已创建，我们需要配置第一个 **Target** 序列的各个部分，使其按我们的意图工作。

## 配置 Make Objects Global 命令

1. 双击 **Make Objects Global** 编辑其属性。
2. 在 **Please Select Objects to Make Global（请选择要设为全局的对象）** 下，勾选所有可用对象，使所有可用对象成为全局对象。回想一下，在 **TargeterInsideFunction** 函数内同样声明了这些对象为全局。
3. 点击 **OK** 保存更改。

> [图 10.4：Make Objects Global 命令配置]

## 配置 Target Desired B-Plane Coord. From Inside Function 命令

1. 双击 **Target Desired B-Plane Coord. From Inside Function** 编辑其属性。
2. 在 **Function（函数）** 下，从下拉菜单选择 **TargeterInsideFunction**。在这个特定例子中，由于我们不向函数传递任何输入，也不从函数接收任何输出，因此无需编辑 Input/Output（输入/输出）菜单。
3. 点击 **OK** 保存更改。

> [图 10.5：Target Desired B-Plane Coord. From Inside Function 命令配置]

## 配置 Report Parameters 命令

1. 双击 **Report Parameters** 编辑其属性。
2. 在 **ReportFile** 下，确保从下拉菜单选中 **rf**。
3. 在 **Parameter List** 下点击 **View**。这将打开一个新的 **ParameterSelectDialog（参数选择对话框）** 面板。务必选择下面 **Report Parameters** 截图中所示的参数。
4. 点击 **OK** 保存更改。

> [图 10.6：Report Parameters 命令配置]
