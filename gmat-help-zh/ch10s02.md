# 配置燃料箱、航天器属性、机动、传播器、差分校正器、坐标系与图形（Configure Fuel Tank, Spacecraft properties, Maneuvers, Propagators, Differential Corrector, Coordinate Systems and Graphics）
> 译自 GMAT R2026a 帮助文档 ch10s02.html

本教程需要打开 GMAT 并加载默认任务。要加载默认任务，点击 **New Mission（新建任务）** 或启动一个新的 GMAT 会话。我们将修改 **DefaultSC**，把航天器初始状态设置为出射双曲线轨迹。

## 创建燃料箱

我们需要创建一个燃料箱，以便查看每次脉冲机动后消耗了多少燃料。稍后我们将修改 **DefaultSC** 资源，把燃料箱挂接到航天器上。

1. 在 **Resources（资源）** 树中，右键点击 **Hardware（硬件）** 文件夹，指向 **Add（添加）**，点击 **ChemicalTank（化学燃料箱）**。将创建一个名为 **ChemicalTank1** 的新资源。
2. 右键点击 **ChemicalTank1**，点击 **Rename（重命名）**。
3. 在 **Rename** 框中输入 **MainTank**，点击 **OK**。
4. 双击 **MainTank** 编辑其属性。
5. 按下表设置各值。

表 10.1 MainTank 设置

| 字段 | 值 |
|------|-----|
| Fuel Mass（燃料质量） | `1718` |
| Fuel Density（燃料密度） | `1000` |
| Pressure（压力） | `5000` |
| Volume（容积） | `2` |

6. 点击 **OK** 保存更改。

## 修改 DefaultSC 资源

我们需要对 **DefaultSC** 做些小修改，以定义航天器初始状态并把燃料箱挂接到航天器上。

1. 在 **Resources** 树中，在 **Spacecraft（航天器）** 文件夹下右键点击 **DefaultSC**，点击 **Rename**。
2. 在 **Rename** 框中输入 **MAVEN**，点击 **OK**。
3. 双击 **MAVEN** 编辑其属性。确保选中 **Orbit（轨道）** 选项卡。
4. 按下表设置各值。

表 10.2 MAVEN 设置

| 字段 | 值 |
|------|-----|
| Epoch Format（历元格式） | UTCGregorian |
| Epoch（历元） | `18 Nov 2013 20:26:24.315` |
| Coordinate System（坐标系） | EarthMJ2000Eq |
| State Type（状态类型） | Keplerian（开普勒根数） |
| Elements 下的 SMA（半长轴） | `-32593.21599272796` |
| Elements 下的 ECC（偏心率） | `1.202872548116185` |
| Elements 下的 INC（倾角） | `28.80241266404142` |
| Elements 下的 RAAN（升交点赤经） | `173.9693759331483` |
| Elements 下的 AOP（近拱点幅角） | `240.9696529532764` |
| Elements 下的 TA（真近点角） | `359.9465533778069` |

5. 现在点击 **Tanks（燃料箱）** 选项卡。
6. 在 **Available Tanks（可用燃料箱）** 下，你会看到 **MainTank**。这就是我们之前创建的燃料箱。
7. 通过把 **MainTank** 移到 **Selected Tanks（已选燃料箱）** 框下，将其挂接到航天器 **MAVEN**。在 **Available Tanks** 下选中 **MainTank**，把它移到右侧 **Selected Tanks** 下。
8. 点击 **OK** 保存更改。

## 创建机动

本教程需要两个 **ImpulsiveBurn（脉冲机动）** 资源。下面我们将重命名默认的 ImpulsiveBurn 并新建一个。我们还会选择之前创建的燃料箱，以便为机动提供燃料。

1. 在 **Resources** 树中，在 **Burns（机动）** 文件夹下右键点击 **DefaultIB**，点击 **Rename**。
2. 在 **Rename** 框中输入 **TCM**（Trajectory Correction Maneuver，轨道修正机动的缩写），点击 **OK**。
3. 双击 **TCM** 编辑其属性。
4. 在 **Mass Change（质量变化）** 下勾选 **Decrement Mass（质量递减）**。
5. 在 **Mass Change** 下的 **Tank** 字段，从下拉菜单选择 **MainTank**。
6. 点击 **OK** 保存更改。
7. 右键点击 **Burns** 文件夹，指向 **Add**，点击 **ImpulsiveBurn**。将创建一个名为 **ImpulsiveBurn1** 的新资源。
8. 将新的 **ImpulsiveBurn1** 资源 **Rename** 为 **MOI**（Mars Orbit Insertion，火星轨道入轨的缩写），点击 **OK**。
9. 双击 **MOI** 编辑其属性。
10. 在 **Coordinate System** 下的 **Origin（原点）** 字段，选择 **Mars**。
11. 在 **Mass Change** 下勾选 **Decrement Mass**。
12. 在 **Mass Change** 下的 **Tank** 字段，从下拉菜单选择 **MainTank**。
13. 点击 **OK** 保存更改。

## 创建差分校正器

我们后面创建的两个 **Target**（ targeting，目标求解）序列需要一个 **DifferentialCorrector**（差分校正器）资源才能运行，因此现在创建一个。设置保持默认值。

1. 在 **Resources** 树中，展开 **Solvers（求解器）** 文件夹（若尚未展开）。
2. 右键点击 **Boundary Value Solvers（边值求解器）** 文件夹，指向 **Add**，点击 **DifferentialCorrector**。将创建一个名为 **DC1** 的新资源。
3. 将新的 **DC1** 资源 **Rename** 为 **DefaultDC**，点击 **OK**。

## 创建坐标系

我们后面将在第一个 **Target** 序列下定义的 BdotT 和 BdotR 约束要求我们创建一个坐标系。后面要创建的 Orbit View（轨道视图）资源也需要坐标系资源才能运行。我们将创建以太阳和火星为中心的坐标系。现在创建它们。

1. 在 **Resources** 树中，右键点击 **Coordinate Systems（坐标系）** 文件夹，点击 **Add Coordinate System（添加坐标系）**。将弹出标题为 **New Coordinate System** 的新对话框。
2. 在 **Coordinate System Name（坐标系名称）** 框中输入 **SunEcliptic**。
3. 在 **Origin** 字段下，选择 **Sun**。
4. 在 **Axes** 下的 **Type**，选择 **MJ2000Ec**。
5. 点击 **OK** 保存更改。你会看到 **Coordinate Systems** 文件夹下新建了坐标系 **SunEcliptic**。
6. 右键点击 **Coordinate Systems** 文件夹，点击 **Add Coordinate System**。将弹出标题为 **New Coordinate System** 的新对话框。
7. 在 **Coordinate System Name** 框中输入 **MarsInertial**。
8. 在 **Origin** 字段下，选择 **Mars**。
9. 在 **Axes** 下的 **Type**，选择 **BodyInertial**。
10. 点击 **OK** 保存更改。你会看到 **Coordinate Systems** 文件夹下新建了坐标系 **MarsInertial**。

## 创建 GMAT 函数

本教程需要一个 **GMATFunction**（GMAT 函数）资源。第一个 target 序列将在此函数内实现。

1. 右键点击 **Functions（函数）** 文件夹，指向 **Add**，指向 **GMAT Function**，点击 **New**。
2. 将打开一个新的 GMAT 函数面板。为函数输入名称 **TargeterInsideFunction**，点击 **OK** 保存更改。
3. 现在打开 **TargeterInsideFunction** 资源，把下面所示的第一个 targeter 序列片段粘贴到该函数中。
4. 粘贴完下面的片段后，点击 **Save As（另存为）** 按钮保存函数。保存后，点击 **Close（关闭）** 按钮关闭 **TargeterInsideFunction** 资源。

```
% Target Desired B-Plane Coordinates in this function:

function TargeterInsideFunction()

BeginMissionSequence

Global 'Make Objects Global' MAVEN DeepSpace_ForceModel DefaultDC ...
EarthView MainTank MarsView MOI NearEarth_ForceModel ...
NearMars_ForceModel rf SolarSystemView TCM


Target 'Target B-plane coordinates' DefaultDC {SolveMode = Solve, ...
	ExitMode = SaveAndContinue}
   Propagate 'Prop 3 days' NearEarth(MAVEN) {MAVEN.ElapsedDays = 3}
   Propagate 'Prop 12 Days to TCM' DeepSpace(MAVEN) {MAVEN.ElapsedDays = 12}
   Vary 'Vary TCM.V' DefaultDC(TCM.Element1 = 0.001, ...
	{Perturbation = 0.00001, MaxStep = 0.002})
   Vary 'Vary TCM.N' DefaultDC(TCM.Element2 = 0.001, ...
	{Perturbation = 0.00001, MaxStep = 0.002})
   Vary 'Vary TCM.B' DefaultDC(TCM.Element3 = 0.001, ...
	{Perturbation = 0.00001, MaxStep = 0.002})
   Maneuver 'Apply TCM' TCM(MAVEN)
   Propagate 'Prop 280 Days' DeepSpace(MAVEN) {MAVEN.ElapsedDays = 280}
   Propagate 'Prop to Mars Periapsis' NearMars(MAVEN) {MAVEN.Mars.Periapsis}
   Achieve 'Achieve BdotT' DefaultDC(MAVEN.MarsInertial.BdotT = 0, ...
	{Tolerance = 0.00001})
   Achieve 'Achieve BdotR' DefaultDC(MAVEN.MarsInertial.BdotR = -7000, ...
	{Tolerance = 0.00001})
EndTarget; 

% Report MAVEN parameters to global 'rf' :
Report 'Report Parameters' rf MAVEN.UTCGregorian TCM.Element1 ...
TCM.Element2 TCM.Element3 MAVEN.MarsInertial.BdotT ...
MAVEN.MarsInertial.BdotR MAVEN.MarsInertial.INC
```

提醒：第一个 target 序列将求解期望的 B 平面坐标，使航天器 **MAVEN** 接近火星。注意我们在函数开头将所有相关对象声明为 global（全局）。这些对象也将在 Mission Sequence（任务序列）中声明为全局。注意在这第一个 target 序列中，航天器 **MAVEN** 先用 **NearEarth** 传播器传播 3 天；接着用 **DeepSpace** 传播器传播 12 天并执行 **TCM** 脉冲机动；再用 **DeepSpace** 传播器传播 280 天，最后传播到火星近拱点。B 平面坐标的期望约束将在火星近拱点处满足。**TCM** 脉冲机动的三个分量是帮助我们实现这两个约束的控制量。注意两个 B 平面约束的容差相当严格。
