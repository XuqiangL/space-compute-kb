# 键盘快捷键（KeyboardShortcuts）

> 译自 GMAT R2026a 帮助文档 KeyboardShortcuts.html

**Keyboard Shortcuts** —— 图形用户界面中的键盘快捷键。

## 描述

GMAT 图形用户界面（GUI）提供了许多键盘快捷键，方便访问常用命令。详见下列各表。

## 通用快捷键

以下键盘快捷键在使用 GMAT 的任何时候都可用。

| 按键 | 作用 |
| --- | --- |
| **Ctrl**+**Shift**+**<数字>** | 打开最近使用的脚本 <数字>（1–5） |
| **Ctrl**+**N** | 创建新任务 |
| **Ctrl**+**Shift**+**N** | 创建新的空脚本 |
| **Ctrl**+**O** | 打开 **Open（打开）** 对话框 |
| **Ctrl**+**S** | 保存当前任务 |
| **F1** | 打开帮助文档 |
| **Ctrl**+**F1** | 打开 **Welcome Page（欢迎页）** |
| **F5** | 运行当前任务 |
| **F9** | 为当前图形窗口播放动画 |
| **F12** | 打开 **Save As（另存为）** 对话框 |

## 树视图快捷键

以下键盘快捷键在浏览资源树、任务树和输出树时可用。

| 按键 | 作用 |
| --- | --- |
| **Enter** | 打开 |
| **空格** | 打开 |
| **Delete** | 删除 |
| **Ctrl**+**Shift**+**C** | 克隆（仅对资源可用） |
| **F2** | 重命名 |
| **Ctrl**+**Page Up** | 查看下一个标签页 |
| **Ctrl**+**Page Down** | 查看上一个标签页 |

## 对话框快捷键

以下键盘快捷键在与对话框交互时可用，例如 `Spacecraft` 资源或 `Propagate` 命令的属性窗口。

| 按键 | 作用 |
| --- | --- |
| **Tab** | 移动到下一项 |
| **Shift**+**Tab** | 移动到上一项 |
| **Ctrl**+**C** | 复制 |
| **Ctrl**+**V** | 粘贴 |
| **Ctrl**+**W** | 关闭 |
| **F1** | 打开针对该功能的帮助 |
| **F7** | 显示脚本 |

## 脚本编辑器快捷键

以下键盘快捷键在使用脚本编辑器时可用。

| 按键 | 作用 |
| --- | --- |
| **Tab** | 插入制表符 |
| **Shift**+**Tab** | 移除当前行的一个制表符 |
| **Ctrl**+**Tab** | 移动到下一个编辑器按钮 |
| **Ctrl**+**Shift**+**Tab** | 移动到上一个编辑器按钮 |
| **Ctrl**+**A** | 全选 |
| **Ctrl**+**C** | 复制 |
| **Ctrl**+**F** | 打开 **Find and Replace（查找替换）** 对话框 |
| **Ctrl**+**G** | 打开 **Go To（转到）** 对话框 |
| **Ctrl**+**H** | 打开 **Find and Replace（查找替换）** 对话框 |
| **Ctrl**+**I** | 增加缩进 |
| **Ctrl**+**Shift**+**I** | 减少缩进 |
| **Ctrl**+**R** | 注释当前行 |
| **Ctrl**+**Shift**+**S** | Save,Sync（保存并同步） |
| **Ctrl**+**T** | 取消注释当前行 |
| **Ctrl**+**V** | 粘贴 |
| **Ctrl**+**W** | 关闭 |
| **Ctrl**+**X** | 剪切 |
| **Ctrl**+**Y** | 重做 |
| **Ctrl**+**Z** | 撤销 |
| **F3** | 查找下一个（在使用 **Find and Replace** 之后） |
| **Ctrl**+**Shift**+**F5** | Save,Sync,Run（保存、同步并运行） |
| **Ctrl**+**Shift**+**F12** | Save As（另存为） |

此外，还可使用以下鼠标控制：

- 按住 **Ctrl** 并滚动滚轮可增大或减小字体大小。
