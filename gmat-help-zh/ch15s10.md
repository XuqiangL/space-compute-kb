# 附录 A：在运行滤波器和平滑器时生成星历（Appendix A. Generate an ephemeris while running the filter and smoother）
> 译自 GMAT R2026a 帮助文档 ch15s10.html

虽然只知道滤波运行的结束状态很有用，但飞行动力学运行通常需要过去（"定轨"）和未来预报轨道的完整星历文件，以协助生成航天器任务运行所需的各种报告和分析。在本节中，我们将展示如何修改滤波/平滑脚本，在滤波器和平滑器运行期间生成星历文件。

1. 如果还没有打开，启动 GMAT 并加载 filter.script 脚本文件。
2. 把以下代码粘贴到脚本中 BeginMissionSequence 命令之前，然后点击 "Save,Sync"。

```
%
%   Create ephemeris files
%

Create EphemerisFile FilterEphem;

FilterEphem.Spacecraft          = EstSat;
FilterEphem.Filename            = 'filter.e';
FilterEphem.FileFormat          = 'STK-TimePosVel';
FilterEphem.IncludeCovariance   = 'Position';
FilterEphem.CoordinateSystem    = EarthMJ2000Eq;
FilterEphem.WriteEphemeris      = False;

Create EphemerisFile SmootherEphem;

SmootherEphem.Spacecraft        = EstSat;
SmootherEphem.Filename          = 'smoother.e';
SmootherEphem.FileFormat        = 'STK-TimePosVel';
SmootherEphem.IncludeCovariance = 'Position';
SmootherEphem.CoordinateSystem  = EarthMJ2000Eq;
SmootherEphem.WriteEphemeris    = False;
```

上述脚本创建两个 EphemerisFile（星历文件）资源实例——一个用于滤波器（filter.e），一个用于平滑器（smoother.e），均为 STK-TimePosVel 格式、包含位置协方差、坐标系 EarthMJ2000Eq，且 WriteEphemeris 暂设为 False。

这里我们创建 EphemerisFile 资源的两个实例——一个用于滤波器，一个用于平滑器。我们把 EstSat 卫星挂接到星历对象，并指定星历格式为 STK 格式星历。由于滤波器在每个测量时刻创建状态，而测量时刻在滤波跨度内通常不是均匀时间间隔，滤波器只能使用支持状态间变时间步长的星历格式。在本例中，我们还选择在 STK 星历中包含协方差（并非所有格式都支持此选项），并指定输出星历的坐标系。

WriteEphemeris 参数告诉 GMAT 是否把所挂接航天器的状态输出到配置的星历文件。我们这里把它设为 False，暂时抑制向星历文件的输出。原因很快就会清楚。

3. 按下面所示更新任务序列，然后点击 "Save,Sync"。

```
%
%   Mission sequence
%

BeginMissionSequence

EstSat.OrbitErrorCovariance = diag([1e-2 1e-2 1e-2 4e-10 4e-10 4e-10]);

Toggle FilterEphem On;
RunEstimator EKF;
Toggle FilterEphem Off;

Toggle SmootherEphem On;
RunSmoother FPS;
Toggle SmootherEphem Off;
```

Toggle 命令用于在适当时机启用和抑制向各星历文件的输出。运行 EKF 之前，我们打开向滤波器星历文件的输出。此时在脚本中，由于 SmootherEphem 资源上 WriteEphemeris 参数的设置，向平滑器星历文件的输出保持关闭。然后我们在打开滤波器星历输出的情况下运行滤波器。滤波器运行时，每个滤波器估计状态都通过挂接到滤波器星历资源的 EstSat 航天器写入滤波器星历。如果此时向平滑器星历的输出也启用，由于 EstSat 也挂接到 SmootherEphem 资源，输出也会写入平滑器星历。这会在平滑器随后运行并再次向平滑器星历文件写入状态时造成问题。

滤波运行完成后，向滤波器星历的输出关闭，向平滑器星历的输出现在打开。然后运行平滑器。平滑器运行期间，来自 EstSat 的输出状态将只写入平滑器星历文件。

4. 点击 "Save,Sync,Run" 按钮、点击工具栏中的蓝色 "Run" 箭头，或按 F5 键运行脚本。

滤波器和平滑器的运行与我们之前所见相同。运行完成后，两个星历文件 filter.e 和 smoother.e 可在 GMAT 输出目录中找到。在本例中，文件只覆盖滤波器和平滑器估计弧段的跨度。GMAT 还可以生成超过跟踪数据结束时间的预报。

5. 把以下代码行添加到平滑器对象的配置中。按下面所示更新任务序列，然后点击 "Save,Sync"。

```
FPS.PredictTimeSpan      = 86400;
```

6. 点击 "Save,Sync,Run" 按钮、点击工具栏中的蓝色 "Run" 箭头，或按 F5 键运行脚本。

此参数指示平滑器在数据结束时间（最后一个观测）之后生成 86400 秒（1 天）的预报。运行完成后检查平滑器星历文件，可看到文件中额外的预报跨度。如果你希望为滤波器添加预报，滤波器也有同样的参数。
