# 配置航天器（Configure the Spacecraft）
> 译自 GMAT R2026a 帮助文档 ch05s02.html

在本节中，您将重命名默认的 `Spacecraft`（航天器），并设置 `Spacecraft` 的初始历元（Epoch）和经典轨道根数。您需要打开 GMAT 并加载默认任务。要加载默认任务，请单击 **New Mission**（新建任务）按钮（> [图：New Mission 工具栏图标]），或启动一个新的 GMAT 会话。

## 重命名航天器（Rename the Spacecraft）

1. 在 **Resources**（资源）树中，右键单击 **DefaultSC**，然后单击 **Rename**（重命名）。
2. 输入 `Sat`。
3. 单击 **OK**（确定）。

## 设置航天器历元（Set the Spacecraft Epoch）

1. 在 **Resources**（资源）树中，双击 **Sat**。如果 **Orbit**（轨道）选项卡尚未选中，请单击该选项卡。
2. 在 **Epoch Format**（历元格式）列表中，选择 **UTCGregorian**。您将看到 **Epoch**（历元）字段中的值变为 UTC 格里历历元格式。
3. 在 **Epoch**（历元）框中，输入 `22 Jul 2014 11:29:10.811`。此字段区分大小写，必须严格按照所示格式输入。
4. 单击 **Apply**（应用）或按 **ENTER**（回车）键保存这些更改。

## 设置开普勒轨道根数（Set the Keplerian Orbital Elements）

1. 在 **StateType**（状态类型）列表中，选择 **Keplerian**（开普勒根数）。在 **Elements**（根数）区域中，您将看到 GUI 重新配置为显示开普勒状态表示形式。
2. 在 **SMA**（半长轴）框中，输入 `83474.318`。
3. 按下表设置其余轨道根数。

**表 5.1. Sat 轨道状态设置**

| 字段 | 值 |
|------|-----|
| **ECC**（偏心率） | `0.89652` |
| **INC**（轨道倾角） | `12.4606` |
| **RAAN**（升交点赤经） | `292.8362` |
| **AOP**（近地点幅角） | `218.9805` |
| **TA**（真近点角） | `180` |

4. 单击 **OK**（确定）。
5. 单击 **Save**（保存）（> [图：Save Mission 工具栏图标]）。如果这是您第一次保存该任务，系统将提示您为文件提供名称和保存位置。
