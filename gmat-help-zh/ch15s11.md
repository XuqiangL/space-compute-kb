# 附录 B：从命令行运行脚本（Appendix B. Run the script from the command-line）
> 译自 GMAT R2026a 帮助文档 ch15s11.html

在本教程中，我们演示了从 GMAT 应用程序图形界面配置和运行 GMAT 滤波/平滑脚本。在任务运行中，定期执行这种点击式操作不可取，最好自动执行。这里我们演示如何从命令行而非图形界面运行滤波脚本。

1. 在你的平台上打开命令行提示符，导航到包含 GMAT 可执行文件的目录。
2. 在该目录中，输入以下命令：
   a. 如果你运行的是 Mac 或 Linux 版本，输入 **GmatConsole** 代替 **gmat.exe**。

```
gmat.exe --exit --run <filter.script 的完整路径>
```

在 Windows/DOS 环境中，这将使 GMAT 启动图形界面、加载并运行脚本，然后退出图形界面。GmatConsole 命令（目前 Windows 不支持）完全不用图形界面运行脚本。在 Windows 平台上，你可以在命令行添加 `--minimize` 选项来抑制图形界面。还有许多其他命令行选项。你可以输入 `gmat.exe --help` 或查看用户指南中的"Command-Line Usage（命令行用法）"。

脚本完成后，你可以检查 GMAT 输出目录，确认命令行运行生成了与我们在图形界面内运行脚本时相同的所有文件。

当然，你可以通过指定 GMAT 可执行文件的完整路径，从任何目录以这种方式运行 GMAT。但请注意，在所有情况下都必须指定脚本的完整路径，即使脚本就在你调用 GMAT 的目录中。GMAT 把所有相对路径视为相对于其自己的 **bin/** 目录。
