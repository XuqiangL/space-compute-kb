# 配置任务序列（Configure the Mission Sequence）
> 译自 GMAT R2026a 帮助文档 ch07s04.html

现在我们将配置一个 **Target**（目标求解）序列，求解将远地点抬升至 `12000` km 所需的有限推力机动时长。我们将首先创建初始的 **Propagate**（传播）命令，然后是 **Target** 序列本身。

## 配置初始 Propagate 命令（Configure the Initial Propagate Command）

1. 单击 **Mission**（任务）选项卡以显示 **Mission**（任务）树。
2. 配置 **Propagate1**，使其传播到 **DefaultSC.Earth.Periapsis**（近地点）。
3. 将 **Propagate1** 重命名为 **Prop To Perigee**（传播至近地点）。

> [图 7.8：Prop To Perigee 命令配置对话框截图]

## 创建 Target 序列（Create the Target Sequence）

现在创建执行 **Target** 序列所需的各条命令。图 7.9"最终任务序列"展示了完成本节各步骤之后 **Mission**（任务）树的配置。我们将在创建完 **Target** 序列之后再对它进行讨论。

> [图 7.9：Final Mission Sequence（最终任务序列）——Mission 树截图]

创建 **Target** 序列的步骤：

1. 在 **Mission**（任务）树中，右键单击 **Prop To Perigee**，指向 **Insert After**（在其后插入），然后单击 **Target**。这将插入两条独立的命令：**Target1** 和 **EndTarget1**。
2. 右键单击 **Target1**，然后单击 **Rename**（重命名）。输入 **Raise Apogee**（抬升远地点），然后单击 **OK**（确定）。
3. 右键单击 **Raise Apogee**，指向 **Append**（追加），然后单击 **Vary**（变量）。将新创建的命令重命名为 **Vary Burn Duration**（改变机动时长）。
4. 右键单击 **Vary Burn Duration**，指向 **Insert After**（在其后插入），然后单击 **BeginFiniteBurn**（开始有限推力机动）。将新创建的命令重命名为 **Turn Thruster On**（开启推力器）。
5. 通过插入表 7.1"其他 Target 序列命令"中所示的命令来完成 **Target** 序列。

**表 7.1. 其他 Target 序列命令**

| 命令 | 名称 |
|------|------|
| **Propagate**（传播） | `Prop BurnDuration` |
| **EndFiniteBurn**（结束有限推力机动） | `Turn Thruster Off` |
| **Propagate**（传播） | `Prop To Apogee` |
| **Achieve**（达成） | `Achieve Apogee Radius = 12000` |

## 配置 Target 序列（Configure the Target Sequence）

现在结构已经创建完毕，我们需要配置 **Target** 序列的各个部分，使其按我们的意图工作。

### 配置 Raise Apogee 命令（Configure the Raise Apogee Command）

1. 双击 **Raise Apogee** 以编辑其属性。
2. 在 **ExitMode**（退出模式）列表中，单击 **SaveAndContinue**（保存并继续）。这会指示 GMAT 在您运行任务之后保存目标求解问题的最终解。
3. 单击 **OK**（确定）保存这些更改。

> [图 7.10：Raise Apogee 命令配置对话框截图]

### 配置 Vary Burn Duration 命令（Configure the Vary Burn Duration Command）

1. 双击 **Vary Burn Duration** 以编辑其属性。我们希望此命令调整（即"Vary"）由先前创建的控制变量 **BurnDuration** 所表示的有限推力机动时长。为此，单击 **Edit**（编辑）按钮，弹出 **ParameterSelectDialog**（参数选择对话框）。使用 **ObjectType**（对象类型）菜单选择 **Variable**（变量）对象类型。此时 **ObjectList**（对象列表）菜单将显示用户定义的变量列表。双击变量 **BurnDuration**，使其出现在 **SelectedValues(s)**（已选值）菜单中。单击 **OK**（确定）按钮保存更改并返回 **Vary Burn Duration** 命令菜单。
2. 在 **Initial Value**（初始值）框中，输入 `200`。
3. 在 **Upper**（上限）框中，输入 `10000`。
4. 在 **Max Step**（最大步长）框中，输入 `100`。
5. 单击 **OK**（确定）保存这些更改。

> [图 7.11：Vary Burn Duration 命令配置对话框截图]

### 配置 Turn Thruster On 命令（Configure the Turn Thruster On Command）

1. 双击 **Turn Thruster On** 以编辑其属性。请注意，该命令已设置为将 **FiniteBurn1** 施加到 **DefaultSC** 航天器上，因此我们无需在此处更改任何内容。
2. 单击 **OK**（确定）。

> [图 7.12：Turn Thruster On 命令配置对话框截图]

### 配置 Prop BurnDuration 命令（Configure the Prop BurnDuration Command）

1. 双击 **Prop BurnDuration** 以编辑其属性。
2. 我们将使用默认的 **Parameter**（参数）值 **DefaultSC.ElapsedSecs**。
3. 在 **Condition**（条件）下，将默认值替换为变量 **BurnDuration**。
4. 单击 **OK**（确定）保存这些更改。

> [图 7.13：Prop BurnDuration 命令配置对话框截图]

### 配置 Turn Thruster Off 命令（Configure the Turn Thruster Off Command）

1. 双击 **Turn Thruster Off** 以编辑其属性。请注意，该命令已设置为结束施加于 **DefaultSC** 航天器的 **FiniteBurn1**，因此我们无需在此处更改任何内容。
2. 单击 **OK**（确定）。

> [图 7.14：Turn Thruster Off 命令配置对话框截图]

### 配置 Prop To Apogee 命令（Configure the Prop To Apogee Command）

1. 双击 **Prop to Apogee** 以编辑其属性。
2. 在 **Parameter**（参数）下，将 **DefaultSC.ElapsedSecs** 替换为 **DefaultSC.Earth.Apoapsis**（远地点）。
3. 单击 **OK**（确定）保存这些更改。

> [图 7.15：Prop To Apogee 命令配置对话框截图]

### 配置 Achieve Apogee Radius = 12000 命令（Configure the Achieve Apogee Radius = 12000 Command）

1. 双击 **Achieve Apogee Radius = 12000** 以编辑其属性。
2. 请注意，**Goal**（目标）已设置为 **DefaultSC.Earth.RMAG**（地心距幅值）。这正是我们所需要的，因此此处不做任何更改。
3. 在 **Value**（值）框中，输入 `12000`。
4. 单击 **OK**（确定）保存这些更改。

> [图 7.16：Achieve Apogee Radius = 12000 命令配置对话框截图]
