# 配置任务序列（Configure the Mission Sequence）
> 译自 GMAT R2026a 帮助文档 ch06s03.html

现在我们将配置一个 `Target`（目标求解）序列，求解将轨道抬升至地球同步高度并使轨道圆化所需的机动值。我们将首先创建一条初始的 `Propagate`（传播）命令，然后是 `Target` 序列本身，最后是末尾的 `Propagate` 命令。为了让我们专注于 `Target` 序列，我们假设您已经通过第 5 章"仿真轨道"（Simulating an Orbit）教程学会了如何将轨道传播到所需的条件。

## 配置初始 Propagate 命令（Configure the Initial Propagate Command）

1. 单击 **Mission**（任务）选项卡以显示 **Mission**（任务）树。
2. 配置 **Propagate1**，使其传播到 `DefaultSC.Earth.Periapsis`（近地点）。
3. 将 **Propagate1** 重命名为 `Prop To Periapsis`（传播至近地点）。

## 创建 Target 序列（Create the Target Sequence）

现在创建执行 `Target` 序列所需的各条命令。图 6.1"霍曼转移的最终任务序列"展示了您完成本节各步骤之后 **Mission**（任务）树的配置。我们将在创建完 `Target` 序列之后再对它进行讨论。

> [图 6.1：Final Mission Sequence for the Hohmann Transfer（霍曼转移的最终任务序列）——Mission 树截图]

创建 `Target` 序列的步骤：

1. 在 **Mission**（任务）树中，右键单击 **Prop To Periapsis**，指向 **Insert After**（在其后插入），然后单击 **Target**。这将插入两条独立的命令：**Target1** 和 **EndTarget1**。
2. 右键单击 **Target1**，然后单击 **Rename**（重命名）。
3. 输入 `Hohmann Transfer`（霍曼转移），然后单击 **OK**（确定）。
4. 右键单击 **Hohmann Transfer**，指向 **Append**（追加），然后单击 **Vary**（变量）。
5. 将 **Vary1** 重命名为 `Vary TOI`。
6. 通过追加表 6.2"其他 Target 序列命令"中的命令来完成 `Target` 序列。

**表 6.2. 其他 Target 序列命令**

| 命令 | 名称 |
|------|------|
| **Maneuver**（机动） | `Perform TOI` |
| **Propagate**（传播） | `Prop To Apoapsis` |
| **Achieve**（达成） | `Achieve RMAG = 42165` |
| **Vary**（变量） | `Vary GOI` |
| **Maneuver**（机动） | `Perform GOI` |
| **Achieve**（达成） | `Achieve ECC = 0.005` |

> **注意（Note）**
>
> 让我们来讨论一下 `Target` 序列的作用。我们知道，执行霍曼转移需要两次机动。我们还知道，对于我们当前的任务，最终轨道半径必须为 42,165 km，最终轨道偏心率必须为 0.005。然而，我们并不知道能够精确实现所需轨道条件的机动大小（即 ΔV 幅值）。您可以使用 `Target` 序列来求解这些精确的机动值。您必须告诉 GMAT 有哪些可用的控制量（在本例中为两次机动），以及必须满足哪些条件（在本例中为特定的轨道半径和偏心率）。这些通过 `Vary` 和 `Achieve` 命令来完成。使用 `Vary` 命令，您告诉 GMAT 要求解什么——在本例中为 `TOI` 和 `GOI` 的 ΔV 值。使用 `Achieve` 命令，您告诉 GMAT 解必须满足什么条件——在本例中为最终轨道条件。

## 创建末尾的 Propagate 命令（Create the Final Propagate Command）

我们需要在 `Target` 序列之后添加一条 `Propagate` 命令，以便查看最终轨道。

1. 在 **Mission**（任务）树中，右键单击 **End Hohmann Transfer**，指向 **Insert After**（在其后插入），然后单击 **Propagate**。此时将出现一条新的 **Propagate3** 命令。
2. 将 **Propagate3** 重命名为 `Prop One Day`（传播一天）。
3. 双击 **Prop One Day** 以编辑其属性。
4. 在 **Condition**（条件）下，将值 `12000.0` 替换为 `86400`，即一天的秒数。
5. 单击 **OK**（确定）保存这些更改。

> [图 6.2：Prop One Day 命令配置对话框截图]

## 配置 Target 序列（Configure the Target Sequence）

现在结构已经创建完毕，我们需要配置 `Target` 序列的各个部分，使其按我们的意图工作。

### 配置 Vary TOI 命令（Configure the Vary TOI Command）

1. 双击 **Vary TOI** 以编辑其属性。请注意，**Variable**（变量）框中的变量为 `TOI.Element1`，默认情况下它是 TOI 在当地速度-法向-副法向（Velocity-Normal-Binormal，VNB）坐标系中的速度分量。这正是我们所需要的，因此保持不变。
2. 在 **Initial Value**（初始值）框中，输入 `1.0`。
3. 在 **Max Step**（最大步长）框中，输入 `0.5`。
4. 单击 **OK**（确定）保存这些更改。

> [图 6.3：Vary TOI 命令配置对话框截图]

### 配置 Perform TOI 命令（Configure the Perform TOI Command）

1. 双击 **Perform TOI** 以编辑其属性。请注意，该命令已设置为将 **TOI** 机动施加到 **DefaultSC** 航天器上，因此我们无需在此处更改任何内容。
2. 单击 **OK**（确定）。

> [图 6.4：Perform TOI 命令配置对话框截图]

### 配置 Prop to Apoapsis 命令（Configure the Prop to Apoapsis Command）

1. 双击 **Prop to Apoapsis** 以编辑其属性。
2. 在 **Parameter**（参数）下，将 `DefaultSC.ElapsedSecs` 替换为 `DefaultSC.Earth.Apoapsis`（远地点）。
3. 单击 **OK**（确定）保存这些更改。

> [图 6.5：Prop to Apoapsis 命令配置对话框截图]

### 配置 Achieve RMAG = 42165 命令（Configure the Achieve RMAG = 42165 Command）

1. 双击 **Achieve RMAG = 42165** 以编辑其属性。
2. 请注意，**Goal**（目标）已设置为 `DefaultSC.Earth.RMAG`（地心距幅值）。这正是我们所需要的，因此此处不做任何更改。
3. 在 **Value**（值）框中，输入 `42164.169`，这是地球同步轨道半径（单位：km）的更精确数值。
4. 单击 **OK**（确定）保存这些更改。

> [图 6.6：Achieve RMAG = 42165 命令配置对话框截图]

### 配置 Vary GOI 命令（Configure the Vary GOI Command）

1. 双击 **Vary GOI** 以编辑其属性。
2. 单击 **Variable**（变量）旁边的 **Edit**（编辑）按钮。
3. 在 **Object List**（对象列表）下，单击 **GOI**。
4. 在 **Object Properties**（对象属性）列表中，双击 **Element1**，将其移入 **Selected Value(s)**（已选值）列表。结果如下图所示。

> [图 6.7：Vary GOI Parameter Selection（Vary GOI 参数选择）对话框截图]

5. 单击 **OK**（确定）关闭 **ParameterSelectDialog**（参数选择对话框）窗口。
6. 在 **Initial Value**（初始值）框中，输入 `1.0`。
7. 单击 **OK**（确定）保存这些更改。

> [图 6.8：Vary GOI 命令配置对话框截图]

### 配置 Perform GOI 命令（Configure the Perform GOI Command）

1. 双击 **Perform GOI** 以编辑其属性。
2. 在 **Burn**（机动）列表中，单击 **GOI**。
3. 单击 **OK**（确定）保存这些更改。

> [图 6.9：Perform GOI 命令配置对话框截图]

### 配置 Achieve ECC = 0.005 命令（Configure the Achieve ECC = 0.005 Command）

1. 双击 **Achieve ECC = 0.005** 以编辑其属性。
2. 单击 **Goal**（目标）旁边的 **Edit**（编辑）按钮。
3. 在 **Object Properties**（对象属性）列表中，双击 **ECC**（偏心率）。
4. 单击 **OK**（确定）关闭 **ParameterSelectDialog**（参数选择对话框）窗口。
5. 在 **Value**（值）框中，输入 `0.005`。
6. 在 **Tolerance**（容差）框中，输入 `0.0001`。
7. 单击 **OK**（确定）保存这些更改。

> [图 6.10：Achieve ECC = 0.005 命令配置对话框截图]
