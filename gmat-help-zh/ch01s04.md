# 平台支持（Platform Support）
> 译自 GMAT R2026a 帮助文档 ch01s04.html

GMAT 已在 Windows 11 平台上经过严格测试，并且我们每晚执行回归测试：针对系统核心运行超过 17,000 个测试用例，针对 GUI（图形界面）运行超过 4,000 个测试用例。Mac 和 Linux 的控制台版本均经过严格测试，但在这些平台上 GUI 以 Beta 形式提供。

以下插件模块在本版 GMAT 的 Mac 和 Linux 平台上无法运行：

- Optimizer libFmincon（优化器 libFmincon）

并且 Mac 版本不支持以下插件：

- libMsise86
