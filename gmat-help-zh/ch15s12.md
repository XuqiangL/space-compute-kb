# 附录 C：检查协方差矩阵的条件数（Appendix C. Check covariance matrix conditioning）
> 译自 GMAT R2026a 帮助文档 ch15s12.html

滤波器容易受到有限机器精度引起的数值噪声影响。这往往表现为协方差矩阵的数值不稳定。如果反向滤波处理起点附近（即前向滤波处理跨度的末端）出现大的数据间隙，Fraser-Potter 平滑器反向滤波步骤的协方差尤其容易出现这种状况。用户可以使用 **plot_cond_cov.py** 工具检查前向滤波器、反向滤波器和平滑器的条件数。

1. 在 Python 脚本目录中，输入以下命令：

```
python plot_cond_cov.py <filter.mat 的完整路径> <smoother.mat 的完整路径>
```

此命令将生成处理跨度内协方差条件数以 10 为底对数的图。能使用 MATLAB 或 Python 的用户可以用滤波器和平滑器 MATLAB 文件对协方差做进一步分析，例如检验协方差特征值是否为正实数，或检查协方差矩阵的对称性。
