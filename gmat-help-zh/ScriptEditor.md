# 脚本编辑器（ScriptEditor）

> 译自 GMAT R2026a 帮助文档 ScriptEditor.html

GMAT 任务既可以在图形用户界面（GUI）中创建，也可以用文本脚本语言创建。当任务从脚本加载到 GUI，或从 GUI 保存时，会生成一个脚本文件，可从资源树的 `Scripts`（脚本）文件夹中访问。打开该脚本时，它会在一个名为 **Script Editor（脚本编辑器）** 的专用编辑器窗口中打开。虽然 GMAT 脚本可以在任何文本编辑器中编辑，但 GMAT 脚本编辑器提供了更多功能，例如：

- GUI/脚本同步
- 从编辑器中执行任务
- 语法高亮
- 注释/取消注释或缩进文本块
- 复制/粘贴、行号、查找替换等标准功能

> [图：脚本编辑器的各部分（标注了主要功能的基本脚本编辑器会话）]

## 活动脚本

当你把脚本加载到 GMAT GUI 时，它会被添加到资源树的脚本列表中。GMAT 同一时间可以加载多个脚本，但只有一个能与 GUI 同步。这个脚本称为活动脚本（active script），在脚本列表中以粗体名称区分。活动脚本的脚本编辑器状态指示器也会显示 "**Active Script**（活动脚本）"。所有其他脚本都是非活动的，但仍可在脚本编辑器中查看和编辑。

> [图：活动脚本指示器]

要与 GUI 同步，你必须通过点击两个同步按钮之一（见下节）把非活动脚本变为活动脚本。这会把当前脚本变为活动脚本、同步 GUI，并把之前的活动脚本变为非活动。或者，你也可以在资源树中右键点击脚本名并点击 **Build（构建）**。

## GUI/脚本同步

GMAT 为任务提供两种独立的表示：脚本文件，以及 GUI 的资源树和任务树。两种表示可以同时打开并保持活动，你可以在两边都做修改。**GUI/Script Sync Status（GUI/脚本同步状态）** 指示器显示两种表示相对于彼此的当前状态。可能的状态如下：

| 状态 | 含义 |
| --- | --- |
| **Synchronized（已同步）** | GUI 和脚本表示已同步（包含相同的数据）。 |
| **Script Modified（脚本已修改）** | 任务在脚本表示中被修改，但尚未同步到 GUI。使用脚本编辑器中的同步按钮执行同步。要还原修改，不保存更改直接关闭脚本编辑器即可。 |
| **GUI Modified（GUI 已修改）** | 任务在 GUI 中被修改，但尚未同步到脚本。要执行同步，点击 GMAT 工具栏中的 **Save（保存）** 按钮。要还原修改，使用脚本编辑器中的同步按钮，或重启 GMAT。 |
| **Unsynchronized（未同步）** | 任务在 GUI 和脚本中都被修改了。更改无法合并；你可以选择保存其中一种表示的修改，或还原其中任意一种。处理方法见上文说明。 |
| **Script Error（脚本错误）** | 脚本中存在错误。这会使 GUI 进入最小安全状态。必须先纠正错误才能继续。 |

> **警告**：保存在 GUI 中执行的修改会覆盖关联的脚本。数据会按预期保存，但会包含完整细节，包括原始脚本中未显式列出的字段和设置。原始脚本的副本会以 ".bak" 扩展名保存在新版本旁边。

脚本编辑器提供两个从脚本到 GUI 执行同步的按钮。**Save,Sync（保存并同步）** 和 **Save,Sync,Run（保存、同步并运行）** 按钮的行为完全相同，只是 **Save,Sync,Run** 按钮在同步完成后还会运行任务。以下段落只描述 **Save,Sync** 按钮的行为，但该描述对两个按钮都适用。如果你在资源树中右键点击脚本名，上下文菜单会显示 **Save, Sync** 和 **Save, Sync, Run** 菜单项，它们与脚本编辑器中的 **Save,Sync** 和 **Save,Sync,Run** 按钮完全相同。

按下 **Save,Sync** 按钮时会执行以下步骤：

1. 保存对脚本的任何修改
2. 关闭所有打开的窗口（脚本编辑器本身除外）
3. 验证脚本文件
4. 通过加载已保存的脚本刷新 GUI
5. 把 **GUI/Script Sync Status** 设为 **Synchronized**

如果 GUI 存在未同步的修改，会显示确认提示；确认后，GUI 修改将被覆盖。

如果脚本不是活动脚本，会显示确认提示；确认后，脚本会先被设为活动脚本，再执行上述步骤。

如果脚本有错误，GUI 会回退到空白基础状态，直到所有错误被纠正且脚本成功同步为止。

## 脚本列表

资源树中的 Scripts 文件夹包含每个已加载到 GMAT 的脚本项。右键点击 **Scripts** 文件夹并点击 **Add Script（添加脚本）**，即可向列表添加脚本。

单个脚本的右键菜单包含以下选项：

- **Open（打开）**：在编辑窗口中打开脚本
- **Close（关闭）**：关闭该脚本所有打开的编辑窗口
- **Save, Sync（保存并同步）**：打开脚本并与 GUI 同步，使其成为活动脚本。等同于脚本编辑器中的 **Save,Sync** 按钮
- **Save, Sync, Run（保存、同步并运行）**：构建脚本（见上文）并运行它。等同于脚本编辑器中的 **Save,Sync,Run** 按钮
- **Reload（重新加载）**：从最后保存的版本重新加载脚本并刷新脚本编辑器
- **Remove（移除）**：从脚本列表中移除该脚本

## 编辑窗口

编辑窗口显示已加载脚本的文本并提供编辑工具。编辑窗口提供以下功能：

- 行号：窗口左侧显示行号
- 语法高亮：GMAT 脚本语言的特定元素会着色以便立即识别
- 折叠：脚本块（如 `For` 循环、`Target` 序列等）可通过点击块起始命令左侧的黑色向下三角形折叠

在编辑窗口中任意位置右键点击，GMAT 会显示包含以下选项的上下文菜单：

- **Undo（撤销）/Redo（重做）**：撤销或重做自上次保存脚本以来的任意数量更改
- **Cut（剪切）/Copy（复制）/Paste（粘贴）**：剪切、复制当前选择，或在光标位置粘贴当前剪贴板内容
- **Delete（删除）**：删除当前选择
- **Select All（全选）**：选择整个脚本内容

当脚本编辑器在 GMAT GUI 中处于活动状态时，Edit（编辑）菜单也可用，包含以下选项：

- **Undo/Redo**：撤销或重做自上次保存脚本以来的任意数量更改
- **Cut/Copy/Paste**：剪切、复制当前选择，或在光标位置粘贴剪贴板内容
- **Comment（注释）/Uncomment（取消注释）**：在当前选择的行首添加或移除注释符号（`%`）
- **Select All（全选）**：选择整个脚本内容
- **Find（查找）/Replace（替换）**：启动 **Find & Replace（查找替换）** 工具（见下文）
- **Show line numbers（显示行号）**：选中时（默认），编辑器窗口在脚本内容左侧显示行号
- **Goto（转到）**：把光标放到指定行号
- **Indent more（增加缩进）/less（减少缩进）**：为当前行或选中内容添加或移除一级缩进。默认缩进为三个空格字符

脚本编辑器中可用的键盘快捷键列表，请参阅键盘快捷键参考页。

## 查找和替换

在 **Edit** 菜单上点击 **Find** 或 **Replace**（或按 **Ctrl**+**F** 或 **Ctrl**+**H**），GMAT 会显示 **Find & Replace（查找替换）** 工具，可用于在活动脚本中查找文本，并可选地替换为不同文本。

> [图：Find & Replace 工具]

要在活动脚本中查找文本，在 **Find What（查找内容）** 框中输入要查找的文本，然后点击 **Find Next（查找下一个）** 或 **Find Previous（查找上一个）**。**Find Next**（**F3**）从当前光标位置向前（向下）搜索，**Find Previous** 则向后（向上）搜索。找到匹配项时会高亮显示。你可以继续点击 **Find Next** 或 **Find Previous** 继续搜索。搜索文本（**Find What** 框中）只能是字面文本，不支持通配符。要把找到的实例替换为不同文本，在 **Replace With（替换为）** 框中输入替换文本。点击 **Replace（替换）** 替换当前高亮的匹配项并高亮下一个匹配项，或点击 **Replace All（全部替换）** 一次替换文件中的所有匹配项。**Find & Replace** 工具会保存当前会话中在 **Find What** 和 **Replace With** 框中输入过的文本历史。点击每个框中的向下箭头可选择之前输入的值。

## 文件控制

**Save（保存）** 按钮保存当前脚本，不检查语法、不与 GUI 同步，也不切换活动脚本。**Save As（另存为）** 按钮与此相同，但允许保存到不同的文件。

**Close（关闭）** 按钮关闭脚本编辑器，并提示你保存任何未保存的更改。

## 保存状态指示器

当脚本内容被修改后，脚本编辑器会在保存状态指示器中显示 "**\*\*modified\*\***"。这是一个可视指示，表示脚本中有未保存的更改。一旦更改被保存或还原，指示器就会变为空白。
