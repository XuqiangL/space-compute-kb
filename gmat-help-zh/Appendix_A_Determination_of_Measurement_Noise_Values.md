# 附录 A——测量噪声值的确定（Appendix A – Determination of Measurement Noise Values）
> 译自 GMAT R2026a 帮助文档 Appendix_A_Determination_of_Measurement_Noise_Values.html（第 13 章"仿真 DSN 测距与多普勒数据"附录）

本节说明我们如何确定所创建的两个 ErrorModel（误差模型）资源的 `NoiseSigma`（噪声 sigma）取值。

## DSN 测距测量的噪声

DSN 测距测量量的计算值由下式给出（Moyer [2000]）：

```
        t3
C ·  ∫  fT(t) dt ,   mod M     (RU)
       t1
```

其中：

- t1, t3 = 分别为发射历元与接收历元
- fT = 地面站发射频率
- C = 与发射机有关的常数（X 频段为 221/1498，S 频段为 1/2）
- M = 测距码长度（单位 RU，测距单位）

注意，上面定义的 M 就等于"定义待仿真测量类型"一节中讨论的 `SimRangeModuloConstant`（仿真测距模常数）。

对上式做变换，可以得到 RU 与米之间的换算关系：

```
C · d(以米计) / c · f̄T = d(以 RU 计)
```

其中：

- f̄T = (∫_{t1}^{t3} fT(t) dt) / (t3 − t1) = 平均发射频率（发射与接收之间）
- c = 光速，单位 m/s
- d = 往返距离

若假设往返距离为 1 米，则有：

```
d(以 RU 计) = C · f̄T / c
```

回顾"创建并配置地面站及相关参数"一节，我们设置了 `DSNTransmitter.Frequency = 7200`，对应 X 频段（故 C = 221/1498）频率 7200e6 Hz。在不使用斜坡表（ramp table）的情况下频率恒定，f̄T = fT，因此：

```
d(以 RU 计) = (221/1498) · (7200e6 / 299792458) = 3.543172 RU
```

本例中，对 DSN 测距测量，我们希望采用 3 米的 1-sigma 噪声偏差（Schanzle [1995]）。由上面的计算可知，这对应于 3 × 3.543172 ≈ **10.63 RU**。

## DSN 多普勒测量的噪声

GMAT 使用的 DSN 多普勒测量实际上是一个导出观测量 O，由两个相继的总计数相位（Total Count Phase）Φ（Trk 2-34 第 17 类记录）测量值计算得到：

```
O ≡ −[Φ(t3e) − Φ(t3s)] / (t3e − t3s)     (Hz)
```

其中：

- t1s, t1e = 发射区间的起点与终点
- t3s, t3e = 接收区间的起点与终点
- Φ = 总计数相位（Trk 2-34 第 17 类记录）

在不存在测量噪声的情况下可以证明（Moyer [2000]），上面的观测值 O 等于下面的计算值 C：

```
C = −M2/(t3e − t3s) · ∫_{t1s}^{t1e} fT(t1) dt1 = −M2/(t1e − t1s) · DCI · f̄T     (Hz)
```

其中：

- t1s, t1e = 发射区间的起点与终点
- fT = 发射频率
- M2 = 应答机转发比（典型值：S 频段 240/221，X 频段 880/749）
- DCI = (t3e − t3s) = 多普勒计数区间（Doppler Count Interval）
- f̄T ≡ (∫_{t1s}^{t1e} fT(t1) dt1) / (t1e − t1s) = 平均发射频率

忽略电离层介质修正，进一步推导（Mesarch [2007]）表明 O 和 C 的值可以与平均距离变化率 ρ̄̇ 联系起来：

```
ρ̄̇_Observed = c · (1 + O / (M2·f̄T)) ,   ρ̄̇_Computed = c · (1 + C / (M2·f̄T))
```

其中：

```
ρ̄̇ ≡ [t3e 时刻的往返距离 − t3s 时刻的往返距离] / (t3e − t3s)
```

于是我们得到：

```
ρ̄̇_Observed − ρ̄̇_Computed = c / (M2·f̄T) · (O − C)
```

上式中的量 (O − C) 代表测量噪声，因此该方程给出了把以 Hz 为单位的测量噪声换算为以 mm/s 为单位的测量噪声的方法。要从 mm/s 换算回 Hz，只需乘以 M2·f̄T/c = M2·f̄T/299792458000。在我们的例子中，使用恒定的 X 频段频率 7.2e9 Hz，换算系数为：

```
(880/749) · (7.2e9 / 299792458000) ≈ 0.0282
```

本教程采用 1 mm/s 的 1-sigma 噪声值（Schanzle [1995]），即对应 **0.0282 Hz**。
