# 审查并质量检查平滑器运行（Review and quality check the smoother run）
> 译自 GMAT R2026a 帮助文档 ch15s06.html

转到你的 *<GMAT 安装目录>*/output 目录。那里应有我们之前见过的滤波器文件，以及两个新文件——smoother.txt 和 smoother.mat。我们从 smoother.txt 开始。

1. 在文本编辑器中打开 smoother.txt 阅读。

smoother.txt 文件与滤波器输出文件格式相同。在顶部，我们看到平滑器初始条件。注意，现在反向滤波器的起始状态是滤波器前向运行的结束状态。力建模、航天器硬件、测量建模与前向滤波器使用的相同。

SMOOTHER MEASUREMENT RESIDUALS（平滑器测量残差）的格式也与 FILTER MEASUREMENT RESIDUALS 报告相同。平滑器残差报告显示相对于平滑器计算状态的测量残差。因此它们按前向时间顺序报告。平滑器在融合前向和反向滤波运行时按前向时间顺序工作。反向滤波运行的残差默认不包含在平滑器输出报告中，但包含在平滑器 MATLAB 文件中。

平滑器输出报告接下来是平滑器测量摘要统计。同样，报告格式与滤波器中的相同。与滤波器一样，我们应预期看到大部分测量被接受。在某些情况下，反向滤波器可能发散并剔除大量测量数据，因此分析人员应仔细审查平滑器输出，以确保这种情况没有发生。

接下来是平滑器状态信息。这是测量数据结束时刻的平滑器状态，因此它与滤波器结束状态完全匹配。请记住，反向滤波器从前向滤波器的结束时刻开始，因此反向滤波器、前向滤波器以及平滑器在最后一个测量处都一致。

最后是 SMOOTHER COVARIANCE REPORT（平滑器协方差报告）。其格式同样与滤波器协方差报告相同，但报告的是平滑器协方差。平滑器的功能是改进估计状态的精度，由于平滑器的数学原理，平滑器协方差总是小于前向滤波器的协方差。这在平滑器输出报告中可能难以看出，但当我们检查平滑器 MATLAB 文件的结果图时会更清楚。现在就这么做。

2. 如果你还没有打开，请打开 DOS 提示符并导航到包含示例 Python 分析脚本的目录。
3. 在该目录中，输入以下命令：

```
python plot_covariance.py <smoother.mat 的完整路径>
```

几秒后，你应看到类似下图的图。把它与我们之前为滤波器位置协方差生成的图比较，注意差异。此图没有呈现前向前向滤波器图中的"收敛"行为，且所有不确定度分量都至少比前向滤波器的小一些。这反映了这样一个事实：平滑器中的每个点都包含从该点过去和未来的测量中获得的信息。相比之下，前向滤波运行中的每个点只包含来自该点过去的信息，因为前向滤波器只按时间前向处理测量。拥有关于特定时间点状态的更多信息（本例中来自该点的过去和未来轨迹）改善了状态认知，从而降低了状态不确定度。

> [图：平滑器位置协方差图]

我们还注意到不确定度的 V 分量呈明显的 U 形。其他分量也显示出在跨度开始和结束处噪声更大的迹象。这同样是平滑器工作方式的结果。靠近跨度起点的状态有大量来自反向滤波器的信息，但来自前向滤波器的信息不多。类似地，靠近末端的状态有大量来自前向滤波器的信息，但来自反向滤波器的信息不多。靠近运行中心的状态拥有来自前向和反向滤波器的最大信息量，因此不确定度最小。

4. 在脚本目录中，输入以下命令：

```
python plot_solve_fors.py <smoother.mat 的完整路径>
```

几秒后，你应看到类似下图的图。它显示平滑器对阻力系数的估计。

> [图：平滑器 Cd 估计图]

平滑器 Cd 估计周围的不确定度包络表现出与位置和速度平滑器图类似的行为。靠近运行的开始和结束处，关于估计的信息较少，因此不确定度比中心附近更大。

滤波器和平滑器运行质量检查的最后一步要求我们生成所谓的"滤波器-平滑器一致性图"（filter-smoother consistency plots）。我们现在有两条完整的航天器状态前向估计时间历程——来自前向滤波器的状态估计，以及来自前向平滑器（经反向滤波后）的状态估计。这些图让我们看到滤波器状态估计和不确定度是否与平滑器状态估计和不确定度"一致"。换句话说，如果前向滤波器把航天器放在某个位置并具有特定不确定度，平滑器状态及其不确定度是否合理地落在滤波器状态和不确定度的范围内？

举例来说，考虑滤波器估计把航天器放在 A 点、不确定度 10 米的情况。现在假设平滑器在同一时刻的估计把航天器放在 B 点、不确定度 5 米。如果 A 点和 B 点之间的距离是 7 米，那么我们可以说滤波器估计与平滑器估计"一致"。A 点与 B 点之间的距离在 A 点和 B 点位置的不确定度之内。

另一方面，考虑 A 点（不确定度 10 米）和 B 点（不确定度 5 米）相距 100 米的情况。滤波器（A 点）和平滑器（B 点）之间估计位置的误差远大于根据各自报告的不确定度应有的预期。在这种情况下，我们说滤波器和平滑器估计不一致，应开始在滤波器或平滑器中寻找建模误差的来源。滤波器-平滑器一致性图将在运行的整个跨度上对每个点执行此比较，并生成一张图，显示代表滤波器和平滑器运行之间一致性水平的度量。

5. 在脚本目录中，输入以下命令：

```
python filter_smoother_consistency.py <filter.mat 的完整路径> <smoother.mat 的完整路径>
```

几秒后，你应看到类似下图的图。它显示滤波器-平滑器位置一致性。

> [图：滤波器-平滑器位置一致性图]

此图显示 VNB 坐标架中航天器位置矢量各分量的滤波器-平滑器一致性。速度一致性图类似。你还应审查所有其他估计参数的滤波器-平滑器一致性。脚本还应已生成阻力系数的一致性图。由于 Cd 只是标量值，Cd 一致性图只显示一个数据序列。一致性度量衡量滤波器和平滑器状态差异相对于其不确定度的大小，因此我们预期在调校良好的滤波器中，该度量的大部分落在 ±3 范围内。如果不是这样，你应开始检查滤波器配置。滤波器-平滑器一致性差的可能来源包括：力建模差、未知或未建模的力（如推力事件）、过多的数据编辑，以及状态噪声或 FOGM 变量调校不当。
