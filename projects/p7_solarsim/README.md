# p7_solarsim — 太阳系轨道 1:1 实时仿真器

零依赖（纯 Python 标准库 + tkinter），启动即与本机真实时钟对齐（UTC）。

## 运行

```
py main.py        # 启动仿真器
py -m unittest test_solar    # 运行 18 项物理验证测试
```

## 物理模型（全部经测试锁定）

| 模型 | 来源 | 精度 |
|---|---|---|
| 行星位置 | JPL 开普勒近似根数表（J2000 + 世纪变率）| 内行星角分级（1800-2050） |
| 月球 | Meeus 低精度地心模型 | 角分级 |
| 轨道力学 | 二体开普勒方程（牛顿迭代，收敛 1e-12） | 与标准测试向量一致 |
| 时间 | 系统时钟 → 儒略日 JD，1:1 实时对齐 | 测试验证 0.2s 内跟踪 |
| 转移 | 霍曼转移（圆轨道共面近似） | 地球→火星 Δv=5.61km/s、259天、相位44.3°、会合780天，全部与教科书一致 |

## 功能

- **实时对齐**：默认 1:1 模式，模拟时刻 = 真实 UTC 时刻；绿色"与真实时间对齐"指示灯
- **时间机器**：暂停 / ×60 / ×1小时/秒 / ×1天/秒 / ×10天/秒 / ×100天/秒 / 倒放；跳转到任意日期
- **3D 视角**：左键旋转、右键平移、滚轮缩放（0.02–300 AU）、跟随任意天体
- **天体信息**：点击行星，实时显示六根数（a/e/i/Ω/ϖ/M）、日心距、速度、周期、与地球距离
- **转移轨道设计器**：
  - 任选出发/到达行星，计算 Δv₁/Δv₂/总Δv、飞行时间、所需相位角、当前相位角、等待时间、会合周期
  - **"若现在发射，到达时错过目标 X 百万公里"**——直观展示发射窗口的物理意义
  - 立即发射（演示轨道形状）/ 等窗口发射（相位对齐，探测器在出发行星上等待，准时点火）
  - 探测器三态显示：等待窗口(橙) → 巡航(青) → 已到达(绿)，带实时航迹
- **太阳系全貌**：八大行星 + 冥王星 + 月球，轨道线、AU 网格、黄道面

## 教学要点（阅读顺序）

1. `kepler.py` — 开普勒方程牛顿迭代；活力公式；儒略日换算
2. `ephemeris.py` — 六根数 → 位置；JPL 表的世纪变率；月球模型
3. `transfer.py` — 霍曼 Δv 推导实现；相位角 φ = π − n₂·TOF；会合周期 1/|1/T₁−1/T₂|
4. `render3d.py` — 球坐标相机 + 透视投影（150 行手写 3D，无 OpenGL）
5. `main.py` — 时间锚定（offset 机制保证实时模式永不漂移）；转移弧参数化

## 已知近似（文档化的）

- 行星轨道按当前瞬时根数画闭合椭圆；长期项（岁差章动）未建模
- 转移用圆轨道共面近似：真实任务（如天问一号）用 patched-conic + 倾角修正，到达脱靶读数即此近似误差

- 未含 N 体摄动；要更高精度需接 SPICE/DE440（网络受限时本表是最佳离线方案）
