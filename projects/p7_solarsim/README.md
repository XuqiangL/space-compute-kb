# p7_solarsim — 太阳系工程仿真器 v2

零依赖（纯 Python 标准库 + tkinter），启动即与本机真实时钟对齐（UTC 儒略日锚定）。

## 运行

```
py main.py                          # 启动仿真器（或双击 启动仿真器.bat）
py -m unittest test_solar           # 18 项：轨道力学/星历/霍曼
py -m unittest test_bodies          # 20 项：卫星/小天体/机动/拉格朗日
```

## 工程要素

- **黄道面 J2000 标注** + 春分点方向箭头 + 1/2/5/10/20/40 AU 网格
- 选中行星显示**近日点/远日点标记**与**升交点线**
- **转轴倾角线**（地球 23.44°、天王星 97.8° 躺着转）
- **土星 C/B/A 三环**（含卡西尼缝，按真实极轴方向）+ 天王星环
- **日地拉格朗日点 L1-L5**（L4/L5 等边三角形几何验证；L2 = JWST 位置）
- **SOI 引力影响球**（a·(m/M☉)^0.4，地球 0.0062 AU）
- 哈雷彗星过近日点（<3 AU）时显示**背日彗尾**

## 机动节点（KSP 式）

1. 转移设计器发射探测器 → 巡航中
2. 输入 Δv → 顺行/逆行点火 → **状态向量转六根数** → 新圆锥曲线实时生效
3. 显示新轨道近日点/远日点；Δv 足够大时进入**双曲线逃逸轨道**（e>1，双曲线开普勒方程传播）
4. 应用：到达目标时逆行点火 Δv₂ = 捕获入轨；顺行点火 = 提升远日点

# 代码全解（逐文件）

共 8 个代码文件约 2000 行。按学习顺序（物理内核 → 界面）讲解，每个函数说明"干什么 + 背后的物理/数学 + 关键实现技巧"。

## 0. 整体架构（数据流向）

```
真实时钟 ──→ kepler.py (时间→儒略日JD)
                │
JPL根数表 ──→ ephemeris.py ──→ 行星位置(AU) ─┐
卫星/小天体表 ─→ bodies.py ──→ 卫星/带/彗星位置 ├─→ main.py 渲染管线 ─→ 屏幕
                │                              │
力学内核 ────→ transfer.py / conics.py ──→ 转移弧/机动 ──┘
                │
            render3d.py (相机投影，谁调用谁传入3D点)
```

**设计原则**：每个文件只做一件事；所有物理函数都可脱离 GUI 单独测试（所以 38 项测试不需要打开窗口）。

## 1. `kepler.py` — 力学与时间内核（最底层）

全项目的数学基石，只有 ~130 行，但每个函数都是航天动力学的标准件。

### 1.1 常数

- `AU_KM = 149597870.7`：天文单位定义值（精确到 0.1 km）
- `K_GAUSS = 0.01720209895`：**高斯引力常数**。用 AU+天做单位时太阳引力参数 μ☉=k²，避免每次写 1.327×10¹¹。真实星历计算（JPL）的同款做法

### 1.2 `solve_kepler` — 开普勒方程求解器（全项目被调用最多的函数）

**物理问题**：开普勒方程 E − e·sinE = M 是**超越方程，无解析解**。已知"平近点角 M"（随时间均匀流逝）求"偏近点角 E"（真实几何位置），只能数值迭代。

**实现技巧**：
- 牛顿迭代 E ← E − f(E)/f′(E)，3-5 次收敛到 1e-12
- 初值选择：`e<0.8` 用 M（低偏心率 E≈M）；`e≥0.8` 用 π（哈雷 e=0.967 防不收敛）——航天教材标准经验
- 测试锁定：M=1.0, e=0.5 → E=1.49870113（教科书标准向量）

### 1.3 `solve_kepler_hyperb` — 双曲线版本（逃逸轨道用）

椭圆用三角函数 sin/cos，双曲线用双曲函数 sinh/cosh，数学结构完全平行。点火超过逃逸速度（1 AU 处 ≈12.3 km/s）后 e>1，必须走这个分支。

### 1.4 `elements_to_state` — 六根数 → 三维位置（坐标变换核心）

三步：
1. 解开普勒方程得 E（双曲线分支求 F）
2. **轨道面内坐标**：x′=a(cosE−e)，y′=a√(1−e²)sinE（椭圆参数方程）
3. **三次旋转**：绕 z 转 ω → 绕 x 转 i → 绕 z 转 Ω，把轨道面"摆"进黄道坐标系（Bate《Fundamentals of Astrodynamics》第 2 章标准公式）

### 1.5 时间系统（实时对齐的基础）

`jd_now()`：**这就是"实时对齐现在时间"的全部实现**——Unix 时间戳 ÷86400 + 2440587.5（1970-01-01 的儒略日）= 此刻儒略日。全太阳系位置都是 JD 的函数，把当前 JD 喂进去，画面就和真实天空严格同步。

`jd_of_ymd`（Meeus 算法）：把"2026-08-05"转成 JD，用于日期跳转与哈雷历元。

## 2. `ephemeris.py` — 行星位置表（JPL 数据）

### 2.1 JPL 根数表（数据心脏）

每颗行星 12 个数：**J2000 时刻 6 个轨道根数 + 每世纪变化率**，来自 JPL 官方"近似位置表"（Keplerian Elements for Approximate Positions），是 NASA 精确星历的长期平均结果。1800-2050 年内行星精度角分级——**不用联网下载几百 MB 的 DE440 也能视觉 1:1**。

注意 Earth 的 L 变率 35999.37°/世纪 ≈ 365.256 天一圈——这个数字本身就是地球公转周期的体现。

### 2.2 插值求任意时刻根数

线性外推：T = 距 J2000 的儒略世纪数，每个根数 = 初值 + 变率×T。然后 ϖ 拆成 ω=ϖ−Ω、M=L−ϖ，喂给 `elements_to_state`。

### 2.3 月球（Meeus 低精度模型）

月球不能用简单开普勒根数（地球+太阳双重摄动）。用 Meeus《Astronomical Algorithms》截断级数：5 个基础角（平黄经、平距角、太阳/月球平近点角、升交点角距）+ 主摄动项。最大的 6.289°·sin(M′) 项即著名的"**出差**"（evection，古希腊人就发现的月球最大不均匀性）。精度角分级。

## 3. `bodies.py` — 扩展天体数据库（v2 主体）

上半部分数据表，下半部分位置函数。

### 3.1 卫星表（21 颗真实卫星）

每颗 6 个数：轨道半径(km)、周期(天)、对黄道倾角、交点、初相位、颜色。Io/Europa/Ganymede 周期 1.769/3.551/7.155 天——**比值精确 1:2:4（拉普拉斯共振）**，太阳系最著名的轨道共振，测试专门验证。

### 3.2 哈雷彗星的历元拟合（真实工程决策）

测试曾抓到：用教科书均值 a=17.834 算 2061 回归是 5 月 31 日，真实预报是 7 月 28 日——差 58 天。原因是木星摄动让每次回归周期不同。**修复方法：像真实星历局那样用本次回归间隔反推 a=17.857**——"吻切根数"（osculating elements）思想的最小实践。

### 3.3 Kirkwood 空隙生成器

2.50/2.82/2.95/3.27 AU 四条"缝"对应与木星的 **3:1、5:2、7:3、2:1 轨道共振**——周期成简单整数比时木星引力扰动周期性叠加，把 asteroid 甩出去。1500 颗用固定种子（seed=42）生成：每次启动画面一致，且测试可验证"没有一颗落缝"。

### 3.4 星空背景（坐标系变换）

恒星星表用**赤道坐标**（赤经/赤纬），仿真用**黄道坐标**，夹角 = 黄赤交角 23.44°。`star_direction` 就是绕 x 轴旋转 23.44° 的标准变换。测试验证天狼星：λ≈104°、β≈−39.6°（与星图软件一致）。

### 3.5 SOI 引力影响球

r_SOI = a·(m_planet/M☉)^(2/5)——行星引力"压倒"太阳潮汐作用的边界。地球 SOI≈92.5 万 km（0.0062 AU），月球在里面所以绕地球转；这是任务设计"何时从日心轨道切换到行星心轨道"的分界线（patched-conic 方法核心）。

## 4. `transfer.py` — 霍曼转移设计（星际导航数学）

### 4.1 Δv 预算

物理图景：转移轨道是以 r₁ 为近日点、r₂ 为远日点的椭圆（a_t 是两者平均）。出发时速度是圆轨道速度 v₁，需加速到转移椭圆近地点速度 v_tp——**Δv₁ 就是两次调用活力公式（vis-viva）的差**。地球→火星：Δv₁=2.95、Δv₂=2.66、总 5.61 km/s、258.9 天，测试与教科书锁定。

### 4.2 发射窗口（本项目最有教学价值的公式）

**推导**：飞半个椭圆（180°）期间目标行星也在走（每天 n₂ 度），所以出发时目标必须"提前" φ = 180° − n₂·TOF 度。地球→火星 = 44.3°。

当前相位不对怎么办？两行星像操场上的两个跑者，相位差以"相对角速度"（= 会合周期 779.9 天的倒数）均匀变化：差多少度 ÷ 相对角速度 = 等待天数。**这就是去火星每 26 个月才有一次机会的原因**。

## 5. `conics.py` — 机动节点（KSP 式玩法的基础）

### 5.1 `state_to_elements` — 状态向量 → 根数（逆问题）

点火瞬间知道位置 r、速度 v，求新轨道的标准算法：
1. **比角动量** h = r×v（轨道面法线，守恒量）
2. **偏心率矢量** e_vec = ((v²−μ/r)r − (r·v)v)/μ，模即 e，指向近地点
3. **比机械能** ε = v²/2 − μ/r → a = −μ/2ε（椭圆 ε<0；双曲线 ε>0 → a<0）

能量法判断轨道类型：**测试里 12.5 km/s 点火后 a<0 即判定双曲线逃逸——不靠猜，靠能量符号**。

### 5.2 机动三段式

- `apply_prograde_dv`：顺行/逆行缩放速度矢量（单位换算 km/s → AU/day）
- `M_from_nu`：真近点角→平近点角（椭圆用反正切、双曲线用 asinh 两分支），教科书常略但工程必备
- `leg_from_state`：把新状态打包成一段"轨道腿"

### 5.3 拉格朗日点

L1/L2 用 Hill 半径近似 r = R(μ/3)^(1/3)（日地 ≈150 万 km，JWST 在 L2）；L4/L5 直接把地球位置矢量旋转 ±60°——**等边三角形解**，测试验证"到太阳距离 == 到地球距离"，这是拉格朗日 1772 年的解析结论。

## 6. `render3d.py` — 手写 3D 相机（150 行替代 OpenGL）

**球坐标相机**：不用 xyz 表示相机位置，而用"绕目标点的方位角/俯仰角/距离"——鼠标拖拽直接改角度，天然实现"环绕观察"（Celestia、KSP 地图模式同款交互）。

核心是 `_basis()` 的**正交基构造**：
1. forward = 相机→目标单位向量
2. right = forward × 世界z轴
3. up = right × forward（三向量两两垂直，构成相机坐标系）

`project()` 即教科书透视投影：世界点转相机坐标后 s_x = f·x_c/z_c，z_c<0（在背后）丢弃。所有 3D 引擎底层都是这个数学，我们只是用 30 行 Python 实现了它。

## 7. `main.py` — 应用层（903 行，两个类）

### 7.1 `Spacecraft` 类（多腿圆锥曲线飞行器）

**关键设计：轨道是一串"腿"（legs）的链表**，不是单条弧。初始只有一条霍曼转移腿；每次点火追加一条新腿（从点火时刻状态向量生成）。`active_leg(jd)` 找当前该走哪条腿——这正是 KSP 机动节点系统的本质数据结构：**过去不可改，未来可规划**。

四态状态机：`waiting`（停在出发行星等窗口）→ `cruise`（沿转移弧）→ `arrived`（挂在目标行星）/ `escaping`（双曲线）。

### 7.2 时间系统（实时对齐的锚）

每 30ms 一帧：
- **实时模式**：模拟时刻 = 此刻 JD + 偏移量——**直接读钟，零累积误差**
- **加速模式**：每帧 += 速率 × 真实流逝时间

跳日期/改速度时更新 offset，切回实时仍无缝。所有天文软件（Stellarium 同款）的时间架构。

### 7.3 渲染管线（_draw 的顺序即图层顺序）

最远 → 最近：星空天球 → 黄道网格/春分点 → 小行星带 → 行星轨道线 → 太阳/行星（+环/极轴/SOI/卫星）→ 拉格朗日点 → 探测器。

各绘制器关键技巧：
- **`_poly`**：统一的"3D 折线→屏幕折线"工具，所有轨道线/网格/环都走它
- **`_draw_belt` 缓存**：1500 颗每帧重算太贵，每 3 帧缓存一次屏幕点——肉眼无感 CPU 减半（时间分片）
- **行星环**：由转轴倾角求极轴 → 垂直极轴平面内构造正交基(u,v) → 按真实半径比画三个圆（C 1.24-1.53、B 1.53-1.95、A 2.03-2.27 行星半径），卡西尼缝就是 B 与 A 之间不画的部分
- **LOD（细节层次）**：卫星视距<2 AU 画点、<0.5 AU 画轨道圈、<0.3 AU 显名；ISS/算星一号只在 <0.02 AU 出现——否则全缩放下满屏噪点
- **双曲线分支**：椭圆腿画整圈（周期/72 段），双曲线腿只画"未来 800 天"开口弧

### 7.4 交互

- `_pick`：遍历所有天体屏幕投影，找 16px 内最近——点击选中
- `_on_tree`+`_focus_selected`：树选中切信息面板；双击把相机 target 设为该天体并按类型预设视距（地球 0.02 AU 看地月系、木星 0.2 AU 看伽利略卫星）
- `_burn`：找巡航中的探测器调 `Spacecraft.burn()`，新根数显示在面板（近/远日点/逃逸警告）

## 8. 测试文件 — `test_solar.py`（18 项）+ `test_bodies.py`（20 项）

**测试即验证文档**：每个 assert 锁定一个独立物理事实，分四类：

1. **标准向量**：开普勒方程 M=1.0,e=0.5 → E=1.49870113；J2000 = JD 2451545.0
2. **教科书数值**：地球→火星 Δv=2.95/2.66 km/s、相位角 44.3°、会合周期 779.9 天、八大行星周期偏差 <0.2%
3. **几何不变量**：转移弧两端点半径严格 = r₁/r₂；L4/L5 等边三角形；恒星方向矢量模长=1；月球圆轨道距母行星=半长轴
4. **物理行为**：顺行点火必升远日点、逆行必降；12.5 km/s@1AU 必双曲线逃逸且 r 单调增；Kirkwood 生成器 1500 颗无一落缝；哈雷两个近日点日期都命中

这套测试已抓到 2 个真实错误（哈雷周期、ISS 周期公式），加上 p1-p6 抓到的 5 处知识库数值错误——**这就是"测试即验证"的价值实证**。
